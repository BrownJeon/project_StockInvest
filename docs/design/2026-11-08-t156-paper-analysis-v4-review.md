## 시그널과 계좌성과를 구별

시그널 생성기간은 ET 장마감 결정 세션(`generated`)으로 필터한다. 실제 구현에서 `createdAt`을 대신 쓸 경우 반드시 그 의미·ET 변환을 계약으로 명시해야 한다. 데모는 49평일에 걸쳐 23개의 서로 다른 역사적 신호를 배치하고 5개 합성 종목을 순환한다. 23개 동시 신규 매수가 아니다. 기본 종목판단의 상위 5종목 제한을 유지한다.

각 신호는 생성일, 다음 합성 거래일 모형 진입(없으면 대기), 실제 관측 최초~최종 날짜, 관측/예상 거래일, 진행중/종료/진입 대기를 표시한다. 선택 생성기간보다 추적기간이 길어질 수 있다. 마지막 11-06 신호는 미래 진입일·가격을 만들지 않고 진입 대기/관측0으로 표시한다. 보유가 진행중이라는 사실은 손익0을 뜻하지 않는다.

현재 DTO에는 개별 신호 귀속손익·평가 완결 계약이 없다. 따라서 `개별 시그널 손익 집계 연결 전`으로 표시하며 임의 수익률·평균을 만들지 않는다. 계좌 탭은 `선택기간 모의계좌성과 (기존 보유 포함)`이다. 이전 기간부터 가진 종목이 영향을 주므로 같은 기간 생성 신호의 성과로 귀속시키지 않는다. 신호별 손익 엔진은 이 요구의 필수 범위로 임의 승격하지 않는다.

## 계좌 기간성과 규칙

같은 계좌/스냅샷/정책에서 선택기간 직전 확인 기준평가→기간 안 마지막 관측까지 기간 수익률·평가손익·MDD를 계산한다. 원래 투자금과 기간 시작 평가액은 별도다. 합성 평가액은 매수/매도 편도 비용 0.25% 차감 후, 외부 입출금 없음이라는 가정이다. 실제 거래별 비용을 재현한 백테스트가 아니다. 합성 값은 날짜 시리즈에서 실제 계산하며 고정 ROI 문구를 넣지 않았다. MDD는 기준평가를 포함한 같은 창의 최고점 대비 낙폭이다. 실현/미실현 손익 분리·신호 귀속손익으로 부르지 않는다.

0~1점, 직전 기준평가 없음, 필요한 과거 관측 누락, 이력 잘림이면 확정 성과를 표시하지 않는다. 기준일까지 완전하나 주/월이 진행 중이면 `부분기간 성과`다. 과거 누락과 진행 중 기간은 다르다. CAGR은 365일 이상 완전 이력이 필요하며 현재 합성 기간은 짧으므로 없음이다. 월 수익률 합산이나 임의 연율화는 없다. 초기 리허설과 전진성과 분리 유지.

페이지는 각각 최대10행이며 요약·성과를 현재 페이지에서 계산하지 않는다. 두 탭의 기간 선택은 공유하고 변경 시 두 목록 페이지1로 재설정한다. 탭 전환은 범위와 각 페이지를 유지한다. 기간 선택이 T0/보유규칙/모델/정책을 재실행하지 않는다. 저장 응답 없는 빈 상태와 정상 알려진0건을 구별한다. 403/오류에서는 이전 비공개 기록과 정책을 제거한다.

## 서버/DTO 계약 제안

기간 기능은 현재 서버에 연결되지 않은 데모 제안이다. 현재 신호 기본20/max100 및 성과1000점 cap의 조회분으로 전체 기간을 계산하면 안 된다.

- 매 요청 로그인·명시 viewer 권한을 먼저 확인하고 account/owner를 조회·count·집계 모두에 적용한다.
- 공통 accountId + snapshotVersion/asOf + 저장 정책 개정 + 기간 종류·시작/끝·ET 기준·신호 생성 의미를 고정한다. snapshot/filter/sort를 cursor에 결속하고 ID tie-breaker를 둔다. pageSize10,totalCount,hasNext/nextCursor, 부족/잘림 상태를 반환한다. 만료/정책 변경 시 새 snapshot page1로 재시작한다.
- 서버가 선택기간 전체로 계좌 집계를 제공한다: prior confirmed baseline(시각/평가액/확인상태), last valuation, observed from/to, elapsed calendar days, expected/observed canonical sessions, missing sessions, partial-to-cutoff, truncation, return/evaluation-P&L/MDD/eligible CAGR. 독립 원래 투자금·T0를 유지한다.
- 시그널 생성 필터의 전체 count/상태별 count와 행별 generation session/time, modeled entry, 실제 관측 최초/최종·예상/관측 세션 수, ongoing/closed/pending 및 완결/누락 출처를 정의한다. 현재 DTO에 없는 귀속손익은 미지원으로 둔다.
- 정책/모델/프롬프트/반영 상태는 현재 env나 mutable account.revision으로 소급하지 않고 선택 run의 영속 기록을 쓴다. 누락이면 미확인. 에이전트 현재 shadow/기본 off와 미구현 정책선택 목표를 구별한다.
- 데이터 기간 선택은 저장 조회만 수행한다. 정책 활성화·매매·예약 실행 변경은 이 제안에 포함하지 않는다.

## 현재 운영과 제안의 차이

부모의 읽기 전용 검산(2026-11-08 08:58:03 UTC, `agent-vault/10-Flow/artifacts/T-156-paper-analysis-v4/t156-ui-v4-period-read.json`)에서는 리허설만 있고 전진 관측이 없었다. 실제 운영 의미는 `전진 미시작 · 성과기간 없음`이다. 이 데모의 9월~11월 관측/성과는 그 운영 결과가 아닌 합성 기간 표시 예시다. 데모 상태 `빈 상태`/품질 `아직 관측 없음`에서 미관측 의미를 검토할 수 있다.

현재 paperPerformance는 최초 전진 평가값→마지막 값 기준이다. 이 제안의 직전 기준평가는 실제 저장·확인된 값이 존재할 때만 사용한다. 합성 T0 08-31의 USD12,000은 별도로 저장 확인된 기준평가라는 가상 전제이며, clone 원래 투자금을 자동 baseline으로 대체·재구성하라는 뜻이 아니다. 새 baseline 자료가 없으면 미확인 또는 현행 기준의 정확한 범위를 표시해야 한다.

시각 구분: 평가 세션은 11-06 장마감 ET, 조회 스냅샷 기준은 11-06 18:05 ET로 나눴다. 보존 출처 수신 11-07 08:00 KST/가용08:01/분석08:05는 각각 11-06 18:00/18:01/18:05 ET로 조회기준 이내다. 시그널 헤더는 같은 생성 필터·조회분의 종료/진행중/진입대기 개수를 따로 표시한다.

기존 의미 유지 수정: 각 신호에 buy/sell 방향을 보존하고 모의 매수/매도 표시를 복원했다. 공통 날짜는 모형 집행으로 표기한다. 상태는 추적 종료/추적중/집행 대기로 구별하며 추적 종료는 포지션 청산·실현손익 확정이나 승리 판정이 아니다. 종료 비율을 승률로 쓰지 않는다.

최종 기간 가시성 보완: 성과 요약에 실제 평가관측 최초~최종 날짜와 합성 거래일 수를 접힘 없이 표시한다. 10월 선택10-01~10-31과 실제관측10-01~10-30·22거래일, 직전기준09-30을 별도 읽을 수 있다. 0점은 없음/미확인, 1점은 동일 날짜 범위·1거래일, 기대일보다 부족하면 누락/부족을 명시한다.
