# T-156 모의성과 v5 예상성과·사후비교 검토 제안

사용자 검토 전 데모다. 예측 엔진/실행/정책 변경의 승인이나 구현 가이드가 아니다. 새 HTML과 이 제안서만 작성했다. v4 원본 SHA256 `ad504e9bc39a22a8bb0fae94703bb8dcd6fca12b9dad60394fb7ae4d6ccacded`와 v4 제안서 `a04c220d09ffc6420960aebfa8ede71e5072014ff0c9a9437c90500549b676c9`는 수정하지 않았다.

## 레이아웃 설계

- 목표: 이미 관측된 계좌성과, 향후 기대 분포, 당시 예측과 이후 모의 관측을 구별한다.
- 위계: 기존 분석 띠·상위3분류·하단5메뉴·고정 한 줄4탭은 유지한다. 모의성과 안에 `관측된 성과 / 향후 예상성과 / 예측 사후비교` 보기 버튼을 추가한다.
- 영역: 관측은 v4의 전체/과거주간/과거월간과 실제 평가관측 범위·기준평가·마지막 평가를 유지. 예상은 고정 11-06 기준의 미래1주/1개월. 비교는 과거에 저장했다고 가정한 합성 원본 이력이다.
- 컴포넌트: 기존 토큰/Section/상태칩/숫자/44px 버튼/페이지 패턴 재사용. 예측 요약은 2열 타일, 상세 가정은 펼침, 비교는 10행 목록.
- 상태: 정상·저장 응답 없음·로딩·오류·403, 유효 경로0, 비교 완료/대기/미확인/비교불가. 비정상 응답은 예측 비공개 값도 제거한다.
- 행동: 보기·기간·검토용 경로·페이지 선택만. 데이터/모델/수집/주문/API/정책 실행 없음.
- 반응형: 360/412px 모바일 우선과 900px 이상 복원을 유지. 내부 보기 버튼은 좁으면 줄바꿈하며 상위4탭은 한 줄 sticky다. 보기 버튼은 aria-pressed와 보이는 글자로 활성 상태를 전한다.

## 현재와 제안

현재 DTO에는 미래 예측·경로·손실확률·예측 원본/사후비교 필드가 없다. 신규 영역은 `미구현 · 검증 전 · 합성 경로 예시`다. 실제 M40 백테스트/예측엔진/에이전트 호출 결과가 아니다. 현재 M40 기본 매매와 에이전트 참고 전용/기본 미호출 상태 및 거래반영 미구현 구분을 유지한다.

관측기간과 미래 horizon은 독립이다. 관측에서 10월을 골라도 예상은 여전히 11-06 기준 미래1주 또는1개월이다. T0/원래투자금/매매규칙을 재설정하지 않는다. 모의계좌 성과는 기존 보유 포함이며 신호 귀속손익이 아니다.

## 미래 기간과 기준

| 항목 | 합성 예시 |
|---|---|
| 예측 평가 기준 | 2026-11-06 장마감 ET |
| 조회 스냅샷/가상 발행 시각 | 2026-11-06 18:05 ET, 실제 원장 아님 |
| 초기 평가액 | 같은 합성계좌의 최신 USD12,343. 원래 투자금 USD12,000과 구별 |
| 향후1주 | 11-07~11-13, 기준일+7달력일. 마지막 합성 평가세션11-13 장마감 |
| 향후1개월 | 11-07~12-06, 다음달 같은날. 마지막 합성 평가세션12-04 장마감 |
| 월말 규칙 | 다음달 같은날이 없으면 월말로 clamp. 01-31→02-28, 윤년02-29, 12-31→다음해01-31 |
| 달력 | 합성 평일 달력. 실제 미국 거래소 휴장/단축일을 검증한 달력이 아님 |

미래 날짜는 대상/예정 세션이며 관측값이 아니다. 현재 예측에는 미래 실제 가격·체결·평가손익이 없다. 실제 구현은 canonical exchange calendar와 평가 완료 영수증을 사용해야 한다. 시각은 평가세션 장마감, 데이터 가용/예측 발행18:05, 목표일, 마지막 평가세션, 관측 완결/성숙 확인 시각을 각각 저장해야 한다.

## 합성 경로 계산

10개 소형 합성 경로 배열에 비용 전 손익, 예측구간 신규 매수 거래대금·신규 매도 거래대금을 둔다. 각 경로의 순손익은 다음과 같다.

`netPnl = grossPnl - buyNotional × 0.0025 - sellNotional × 0.0025`

기존 보유의 과거 매수 수수료를 다시 차감하지 않는다. 회전율이 달라지므로 초기평가액의 고정 왕복0.5%와 동일하다고 부르지 않는다. 편도0.25% 유지. 체결가격차0, 세금/환율 변화/외부 입출금 미반영이라는 예시 가정이다. 관측 사후 평가액도 같은 순비용 가정이다.

기대손익은 유효 경로 순손익의 산술평균이다. P10/P90은 정렬된 순손익의 `(N−1)×p` 위치 선형보간이다. 중앙80% 범위를 USD와 초기평가액 대비%로 표시한다. 손실확률은 `netPnl<0 경로수 / 유효경로 전체수`다. 0손익 경로는 분모에 포함한다. NaN/무효/음수 거래대금 경로는 제외하며 N=0이면 평균/범위/확률 미확인이다.

| horizon | 평균 순손익USD | P10USD | P90USD | 손실비율 |
|---|---:|---:|---:|---:|
| 1주 | 85.70625 | -286.45875 | 491.87125 | 4/10=40% |
| 1개월 | 188.55375 | -630.20925 | 1082.11675 | 4/10=40% |

숫자는 경로 배열의 계산 결과이지 고정 허구 확률 문구가 아니다. 다만 이 배열 자체가 합성이고 예측 정확도/보정 수준은 미검증이다. 손실확률은 에이전트 확신도가 아니다. P10–P90은 최대손실·수익 보장이나 확률 보정 인증이 아니다.

## 사후비교 원본과 상태

23개는 `당시 저장했다고 가정한 합성 예측`과 이후 합성 계좌 평가를 비교하는 시나리오다. 실제 과거 예측 원장이 존재했다는 주장이 아니다. 각 원본에는 forecastId, 기준일/발행시각, horizon, 시작/targetEnd/평가예정세션, baseline, account, policy/data/model/fee 판본과 경로가 있다. 신규 예측은 새 ID로 저장하고 원본을 덮지 않는 계약을 제안한다.

- 완료: targetEnd가11-06 이하이고 마지막 평가세션이 도래했으며 관측2점 이상·필요 세션 완전·동일 계좌/정책/기준/비용인 경우만. 예측 평균/80%범위/손실확률과 관측 순손익·오차(관측−평균)·범위 안/밖을 표시한다.
- 대기: 아직 targetEnd/평가세션 미도래. 미래 관측 손익 없음.
- 미확인: 관측0/1점·누락·기준평가 없음·유효 경로 없음 등. 확정 관측손익/오차 없음.
- 비교 불가: 정책·계좌·baseline·비용 조건이 달라 동일조건 비교가 아님. 확정 비교손익/오차 없음.

관측 결과는 모두11-06 이하이다. 과거 원본별 실제 관측 창과 거래일 수를 보여준다. 단일 예측의 손실확률을 정답/오답으로 단정하지 않는다. 범위 내 여부도 한 관측의 비교이며 보정·정확도 검증을 대신하지 않는다. 전체 요약은 23원본 중 완료9/비교불가3/미확인6/대기5이며 페이지와 무관하다. 비교목록은10/10/3행이고 관측목록 페이지와 별도 상태다. 실제 정량 정확도는 미검증으로 유지한다.

## 필요한 API/저장 계약 제안

현재 DTO를 일부 조회해 미래 예측이나 전체 이력 성능을 계산하면 안 된다. 서버 작업은 데모 검토 이후 별도 구현 범위다.

1. 매 요청 로그인·명시 viewer·owner/account 범위를 query/count/summary에 적용. 같은 snapshot/filter/sort와 tie-breaker ID에 cursor 결속. pageSize10,totalCount,hasNext/nextCursor, 누락/잘림/만료 반환. 예측/비교 원본은 immutable ID/version/hash·createdAt으로 보존.
2. 예측 계약은 account/policy/data/model/prompt/fee/calendar 판본, asOf valuation과 availableAt/issuedAt, horizon 규칙·targetStart/end·scheduledEvaluationSession·maturityAt, baseline확인시각/금액, 유효/제외 경로수, 순손익분포/quantile방법/손실확률분모, 비용/세금/FX/입출금 가정을 포함한다. 현재 runtime/env로 과거 판본을 소급 추정하지 않는다.
3. 예측 입력과 미래 관측을 시간적으로 분리해 발행시점 이후 정보 혼입을 막는다. 사후 원본이 수정되면 새 예측ID로 취급하며 과거 예측 원본을 이후 값으로 덮지 않는다.
4. 비교는 동일 계좌·baseline·정책·비용의 관측 완결 영수증·최초/최종 관측·expected/observed session/gaps와 변경 여부를 확인한 서버 판정이 필요하다. 미성숙은 관측값을 반환하지 않는다. 비교 기준/대상 전체 count를 현재20/100/1000 cap이나 현재페이지로 대체하지 않는다.
5. 실예측의 분포 모형·검증자료·확률 보정·backtest/out-of-sample 기준은 이 UI가 정하지 않는다. 새 전략/임계값/agent호출/주문 연결을 임의 도입하지 않는다. 예측 엔진·모형 실행 권한도 이 데모 승인으로 생기지 않는다.

## 자체 점검과 검증 범위

designer.toml 및 단계별5스킬 재읽기: page-layout-designer, ui-component-builder, project-ui-system(부분/모바일), ui-design-reviewer, ui-accessibility-reviewer. 정적 자체 점검 P0 0·P1 0, a11y Critical0·Major0; P2/Minor1은 실제 브라우저/스크린리더 확인 전 제한이다.

JS VM으로 horizon/월말/윤년/연교차, 비용·평균·선형P10/P90·0손익분모·N0/NaN, 23원본 성숙/상태/오차, 10/10/3페이지, 미래 관측 부재, 과거 관측기간과 미래 horizon 독립, 빈/오류/403 비공개 예측값 제거를 확인했다. 부동소수 비교는1e-9 허용오차로 대조했다. Lint T-156-v5 통과. 부모가 독립 검토와360/412/1280px CUA를 진행하며 사용자 검토 전 앱 구현은 하지 않는다.

주요 선택기: `[data-performance-view]`, `#forecast-horizon`, `#path-fixture`, `#comparison-records`, `[data-comparison-page]`. 기존 `#state`, `#count`, `#period-kind`, `#period-key`, `#integrity`와 상위 `[data-tab]`은 유지한다.

등록 전 보완: 미래/비교 수치 근처에 매수·매도 각0.25% 비용을 접힘 없이 표시했다. 과거 비교의 유효경로0도 null 통계에서 렌더가 중단되지 않도록 미확인/0경로를 표시하며 기존 미확인 원본 하나를 N0 검토 예시로 둔다. 최상단 검토 배너는 v5의 관측/예상/사후비교 추가를 명시한다.

추가 경계: 현재 미래 예시 forecastId에 horizon뿐 아니라 정책 시나리오판본을 결속했다. 첫 역사적 예측의 사전 합성 경로를 좁게 구성해 관측 원장을 바꾸지 않고 완료·범위 밖 사례를 포함한다. 이는 원본을 실제 사후 수정했다는 뜻이 아닌 합성 fixture 설계이며 확률 정답/오답 판정은 하지 않는다.

최종 CUA 디자인 상태 보완: 내부 성과 보기의 aria-pressed=true 버튼은 기존 accent 테두리·3px 하단선과 bg4 배경으로 활성 상태를 가시화했다. 색 외에도 하단선 형태 차이를 제공하며 기능/수치/배치는 바꾸지 않았다.
