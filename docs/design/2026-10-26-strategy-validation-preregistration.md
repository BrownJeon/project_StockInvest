# 전략 검증 — 합격 기준 사전 등록(P2) + 일봉 백테스트 구현 명세(P3) · 초안 v0.1

> **상태**: 초안(v0.1, 2026-10-26 오후 KST). **사용자가 §A-1 표를 확정하면 v1.0 으로 복제·동결**하고 §B 본문의 sha256 을 기록한다. **동결 뒤에는 이 문서를 고치지 않는다. 고칠 일이 생기면 새 버전(v1.1, v2.0)을 만들고 무엇이 왜 바뀌었는지 적는다.** 결과를 본 뒤 기준을 느슨하게 바꾸는 것은 새 버전으로도 하지 않는다(통합 절차서 §7.3).
> **근거 표기**: `[확실]` = 이번 세션에서 코드·문서·DB(읽기 전용)로 직접 확인 · `[가능성 높음]` = 강한 추론 · `[추측]` = 빈틈을 추정으로 메움. 이 문서의 수치 기준 대부분은 **Analyst 의 제안값**이고 사용자가 확정해야 효력이 있다.
> **무결성 선언**: 이 초안을 쓰는 동안 후보 전략의 수익률·승률·초과수익을 `daily_bars` 로 계산하지 않았다. 실행한 DB 조회는 커버리지·전략 목록·가상 체결 건수·설정 키 5건(§B-0)뿐이다. 인용한 기준선 수치(무조건 진입 5일 평균 US +0.53%·KR +0.76% 등)는 [[T-070-daily-bars-phase0]] Analyst 검토(10-24)에 이미 있던 값이다.

## A. 5줄 요약 (개발자가 아닌 사용자용)

1. **"사전 등록"은 계정이나 사용자 등록이 아니다.** 시험 결과를 보기 *전에* "몇 점이면 합격"을 종이에 못 박아 두는 일이다. 결과를 본 뒤 기준을 정하면 좋은 숫자만 골라 통과시키게 되어(과적합·사후 합리화) 실제 돈을 넣었을 때 성과가 재현되지 않는다.
2. **이 문서는 그 "합격 기준표"의 초안**이다. 사용자가 할 일은 §A-1 표의 항목(숫자·규칙 14개)을 읽고 "권고대로" 또는 바꿀 항목만 말해 주는 것이다. 그 뒤 문서를 동결하고 백테스트를 돌린다.
3. **무엇을 시험하나**: 지금 가진 3년 일봉(미국 50종목·국내 43종목)으로 "일봉 규칙으로 사면 비용을 빼고도 그냥 들고 있는 것보다 나은가"를 전략 후보 10개에 대해 묻는다. 판정 대상(합격하면 실매매 재개 후보)은 3개, 나머지 7개는 참고용이다.
4. **가장 불편한 사실**: 기본 기대치는 *대부분 불합격*이다([[T-064-profit-engine-design]] §0-4, 제 추정 "판정 대상 3개가 모두 불합격일 확률 55~75%" `[추측]`). 불합격도 유효한 결과다 — "이 방법으로는 엣지가 없다"를 싸게 확인하는 것이 토큰을 계속 태우는 것보다 낫다. 그때의 선택지는 §E-3 에 적었다.
5. **일정**: 결정일은 **2026-12-07**(P3 승인 10-26 + 6주, T-064 §6.7). 그 전에 중간에 멈출 수 있는 지점이 3곳(§D-4) 있다.

### B-1. 후보 전략 (정의·가설·격자)

공통: 신호는 **D 일 확정 일봉까지만** 입력받는 순수 함수(§C-2). 지표는 기존 `src/lib/strategy/indicators`(RSI·SMA·EMA·Bollinger·ATR)와 같은 수식. 아래 "고정 상수"는 자유 파라미터가 아니고 등록으로 못 박는 값이다. 격자에는 **라이브 값을 반드시 포함**한다.

#### Tier A — 판정 대상 (합격 시 `backtested` 승급 후보, U13)

**S1 `rsi-oversold-daily`** — `rsi-oversold-v1`(30분~1h 봉, 매수 전용) 의 **일봉 아날로그**. 이름이 같아도 **다른 전략**이다(봉 간격이 다름) — "가족 수준" 증거로만 연결한다(§B-10).
- 가설: 대형 유동주가 단기 과매도(RSI14 < th)·MA20 아래에서 반전 캔들(양봉 또는 저점 상승)을 내면 5~10거래일 안에 평균회귀한다.
- 경제적 근거·상대방: 단기 과잉반응에 유동성을 공급하고 보상을 받는다. 상대방 = 손절·강제 청산하는 단기 매도자. **반대 증거**: 사후검증 v1/v2 에서 30분~1h 룰은 같은 기간 유니버스 무조건 진입(US +0.53%·KR +0.76%, D+5) 보다 나빴다(T-070 Analyst §0-1) → 사전 확률 낮음 `[가능성 높음]`.
- 일봉 정의: `RSI14(close) < th` ∧ `close < MA20 × 1.005`(라이브 `rsiSellPriceMult=1.00` → `×1.005`) ∧ (`close > open` ∨ `low ≥ low_prev`). 봉 ≥ 22.
- 자유 파라미터: `th ∈ {30, 35, 38}`(라이브 38) × `hold ∈ {5, 10}` × `stop ∈ {3%, 5%}` = **12** × 레짐 on/off = **24**.
- 동시 신호 순위: RSI 낮은 순.

**S2 `pullback-trend-daily`** — H1, `pullback-trend-v1`(30분) 의 일봉판.
- 가설: 상승추세(EMA20 > EMA60, MA20 상승) 종목이 RSI 40~50 구간으로 조용히 눌린 뒤 양봉으로 RSI 가 반등하면 추세가 재개된다.
- 경제적 근거·상대방: 추세추종 자금의 재진입 수요. 상대방 = 조기 이익실현자. T-064 가 "안정 지향"으로 분류.
- 일봉 정의(라이브 조건 그대로): `close > open` ∧ `close > MA20` ∧ `MA20 > MA20_prev` ∧ `EMA20 > EMA60` ∧ 최근 5봉 내 `RSI14 ∈ [lo, lo+10]` 터치 ∧ `RSI14 > RSI14_prev`. 봉 ≥ 65.
- 자유 파라미터: `lo ∈ {35, 40, 45}`(라이브 40/50 → lo 40) × `hold ∈ {5, 10}` × `stop ∈ {3%, 5%}` = 12 × 레짐 on/off = **24**. 고정: lookback 5봉, 밴드 폭 10.
- 동시 신호 순위: `|close − MA20| / MA20` 작은 순.

**S4 `xs-momentum`** — H3 횡단면 모멘텀 로테이션.
- 가설: 6~12개월 상대강도 상위 종목이 다음 1개월에도 유니버스 평균을 이긴다(최근 1개월은 단기 반전 때문에 제외).
- 경제적 근거·상대방: 과소반응·처분효과·자금 흐름의 지속. 상대방 = 승자를 너무 빨리 팔고 패자를 쥔 투자자. **위험**: 모멘텀 붕괴(급반전) 때 낙폭이 크고, 50종목 유니버스에선 상위 k 가 업종 집중될 수 있다.
- 정의: 매월 첫 거래일 종가 기준 `ret = close_{t−21} / close_{t−21·L} − 1`(L 개월, 최근 1개월 건너뜀) 상위 k 종목을 **동일가중**으로 다음 달 첫 거래일 시가에 보유 교체. 레짐 필터(유니버스 EW 지수 < MA100 → 전량 현금) 내장.
- 자유 파라미터: `L ∈ {6, 12}` × `k ∈ {10, 15}` × 레짐 on/off = **8**. 고정: 월 1회 리밸런스, 보유 1개월, 손절 없음(포트폴리오 전략).
- 표본 단위: **포지션-월**(한 종목 한 달 보유 = 1). IS 20개월 × k=10 = 200 → U5 충족 가능.

**S7 `control-spike-contraction`** — H4 급등 후 수렴 **대조군**(판정 대상 아님, 합격해도 승급 불가). 20봉 내 +15% 이상 급등 뒤 5봉 ATR 수축 후 5봉 고점 재돌파. `hold ∈ {5, 10}`, stop 5% 고정 = **2**. 목적: 분산이 큰 패턴이 같은 틀에서 어떻게 보이는지 비교 기준.

### B-5. 기준선과 생존편향 할인 (U9)

1. **같은 D0 날짜 유니버스 동일가중 수익**(1차 관문의 기준): 전략 거래의 `ret_h` 에서 같은 D0·같은 시장·같은 h 의 유니버스 평균 `ret_h`(모든 종목, 같은 `d1open` 진입·같은 비용) 를 뺀 **초과수익**. 정의는 T-095 `universeBaselines`·`attachBaselines` 와 같아야 하며 P3 는 **고정 입력 6지점 패리티 시험**으로 같음을 증명한다(§C-4).
2. **지수 ETF 보유**(2차 관문·δ 측정): 미국 `SPY`(KIS 거래소 코드 `AMS` 추정 — **확인 필요**), 국내 `069500`. **P3 결과 실행 전에 `POST /api/cron/daily-bars` 로 2종목 3년 수집**(Leader, 오프아워, 약 16호출, LLM 0, 운영 DB 쓰기는 `daily_bars` upsert 만 — T-070 승인 범위 안). 수집이 안 되면 U9 대안.
3. **생존편향 할인 δ**: `δ_annual = max(0, CAGR(93종목 EW, 월 리밸런스, 같은 창) − CAGR(지수 ETF))`. 거래당 `δ_trade = δ_annual × (평균 보유 거래일 ÷ 252)`. **절대 순기대값 조건(+0.40%/+0.30%)은 `순기대값 − δ_trade` 로 판정**한다. 초과수익(1번)에는 적용하지 않는다(같은 유니버스 대비라 1차로 상쇄됨).
4. **현금**(0%): MDD·샤프 표의 참조.
5. 코스닥150·"BTC 보유"는 쓰지 않는다(T-064 §6.6).

### B-6. 합격 조건 (수치 — 해석 여지 없이)

판정은 **전략(가설) 단위**로 하고, 격자의 각 조합은 **시행**이다. 전략 PASS = "고원 조건(§B-7)을 만족하는 파라미터가 있고, 그 중앙값 조합이 IS 전 조건 → OOS 1회 전 조건을 모두 통과".

**1차 관문 — 거래 수준 (US, 비용 후, `d1open`)**

| # | 조건 | IS | OOS |
|---|---|---|---|
| 1-1 | 표본(미달 = `INSUFFICIENT`, 불합격 아님) | 에피소드 ≥ 150 · 서로 다른 주 ≥ 40 · 기여 종목 ≥ 15 | ≥ 80 · ≥ 20주 · ≥ 10종목 |
| 1-2 | 단일 종목 손익 비중 | ≤ 15% | ≤ 15% |
| 1-3 | 같은 날 유니버스 대비 초과수익(h 는 격자의 hold) | 주 군집 부트스트랩 95% 구간 **하한 > 0** 이고 t ≥ 2.5(N ≤ 100) / 3.0(N > 100) | 구간 **하한 > 0** |
| 1-4 | 순기대값 − δ_trade | ≥ **+0.40%** | ≥ **+0.30%** |
| 1-5 | Profit Factor / 손익비(평균 이익 ÷ 평균 손실) | ≥ 1.4 / ≥ 1.5 | ≥ 1.3 / ≥ 1.5 |
| 1-6 | 비용 민감도 | 슬리피지 ×1.5 에서 순기대값 ≥ 0 | 같음 |
| 1-7 | IS 내부 3폴드 | ≥ 2폴드 양(+) 초과수익 · 한 폴드 이익 ≤ 총이익 60% | — |

**2차 관문 — 포트폴리오 수준 (§A-2 시뮬 설정, 일별 평가손익)**

| # | 조건 | IS | OOS |
|---|---|---|---|
| 2-1 | 샤프(√252) | ≥ 1.0 | ≥ 0.7 **이고** ① 동일가중 벤치마크 샤프 초과 |

**판정값**: `PASS`(1차·2차 IS+OOS 전부) / `REJECTED`(어느 조건이든 실패) / `INSUFFICIENT`(1-1 미달 — 재시험은 유니버스 확장 뒤 새 버전) / `UNTESTED_OOS`(IS 실패로 OOS 미실행). Tier B·S7·국내는 같은 표로 **보고만** 하고 상태는 `EXPLORATORY`.

### B-7. 고원 선택 (U14)

IS 에서 1차 관문 1-3~1-7 을 만족하는 조합의 집합 P 를 만든다. P 의 조합 중 **격자상 이웃(각 파라미터 ±1 스텝, 레짐 플래그는 같은 값) 이 모두 P 에 속하는 것**만 "고원"이다. 고원이 비면 전략 REJECTED(IS). 고원이 있으면 **각 파라미터의 중앙값 조합**(짝수면 보수 쪽: th 낮은 쪽·stop 좁은 쪽·hold 짧은 쪽)을 OOS 에 보낸다. OOS 는 그 1조합만.

### B-8. 실패 처리와 결정일 (U10·U11)

- OOS 실패 → `REJECTED` + 전 지표 기록. **같은 가설의 파라미터 조정·재시험 금지.** 레짐·순위·보유일·청산 종류 4축 분해에서 양(+)인 하위 집합이 보이면 **새 가설로 새 버전에 등록**(T-064 §6.7-2) — 이번 OOS 데이터는 그 새 가설의 OOS 로 **다시 쓸 수 없다**(이미 봤으므로 IS 로 격하).
- **결정일 2026-12-07**: 그날까지의 결과로 Leader 가 사용자 보고. Tier A 3개 전부 `REJECTED`/`INSUFFICIENT` 면 §E-3 선택지를 결정으로 올린다.
- `rsi-oversold-v1` 결정일 = min(S1 OOS 리포트일, 2027-03-09) — §B-10.

### B-9. 전진 페이퍼·T-072 승급 연결 (U13 — 중복 결정 금지)

T-072 의 상태 3단계를 그대로 쓰고 **여기서만** 조건을 정한다(T-064 D4 = T-072 "합격 기준 사전 등록" = 이 절).

### C-2. "백테스트 = 라이브 동일 코드"의 구현 방식

- 신호 함수는 `src/lib/profit-engine/backtest/signals/<id>.ts` 의 `evaluate(frame, i, params)` **하나**다. 라이브(Phase 3 배선 task)는 `daily_bars` 에서 만든 같은 `Frame` 으로 같은 함수를 호출한다. KIS 실시간 봉으로 다시 만들지 않는다.
- **룩어헤드 차단을 시험으로 고정**: `evaluate(frame, i)` 는 `frame.bars[i+1..]` 를 어떤 값으로 바꿔도 결과가 같아야 한다(변이 시험 — 미래 봉을 난수로 덮고 재호출).
- 지표: 기존 `src/lib/strategy/indicators/*`(순수 함수) 재사용이 원칙(T-064 §6.2). **단, 현재 격리 시험 `isolation.test.ts:101` 의 needle `'@/lib/strategy'` 가 이 import 를 금지한다** `[확실]`. 권고: needle 을 `@/lib/strategy/indicators/(rsi|sma|ema|bollinger|atr)` 만 허용하는 정규식 허용목록으로 좁히고, 그 5개 모듈이 서로와 표준 라이브러리 외 아무것도 import 하지 않음을 **같은 시험에서 단언**(순수성 고정). 격리 시험은 의도된 방어선이므로 이 변경은 **Leader 승인 + Reviewer scope 포함**. 대안: 지표를 profit-engine 안에 복제하고 기존 지표와 고정 입력 패리티 시험 — 코드 중복·수식 괴리 위험.
- 라이브 배선(승급 이후)이 생기는 순간 `src/lib/profit-engine/backtest/signals/` 는 **사실상 안전 경로**가 된다 → 그때 `SAFETY_PATHS` 에 `'^src/lib/profit-engine/backtest/signals/'` 추가를 사용자 결정으로 올린다(훅 변경).

## E. 위험·확인하지 못한 것

### E-1. 가장 약한 가정 3개 (먼저)

1. **유니버스가 사후 선택이다** `[확실]`. 93종목은 "지금 살아남은 대형주"라 과거 구간 수익이 상향 편향(승자 선택). 같은 유니버스 대비 초과수익과 δ 할인으로 *일부* 상쇄하지만 **방향이 낙관 쪽인 것은 그대로**다. PASS 는 "이 93종목에서 이 규칙이 그냥 들고 있기보다 나았다"까지만 말한다. PIT 유니버스(≥150, `universe_snapshots`)는 지금부터 쌓여야 하고 과거 구간은 복원 불가(T-064 §5.5).
2. **비용·체결이 옛 가정이다** `[가능성 높음]`. 슬리피지 0.15%·정수 달러 반올림·지정가 추격의 실제 값은 미측정(T-087 브로커 체결 원장이 측정 시작). 민감도 ×1.5 조건으로 완충했지만 저유동 종목·갭 장세에서는 더 클 수 있다.
3. **3년은 레짐이 하나다** `[가능성 높음]`. 2024~2026 미국은 대체로 상승장. OOS(2025-10~2026-10) 에 약세장이 없으면 "약세장에서의 MDD" 조건은 시험되지 않은 채 통과한다. 레짐 필터 on/off 를 격자에 넣은 이유이지만, 필터 자체도 상승장에서만 검증된다.
