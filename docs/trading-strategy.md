# 투자 원칙·매매 전략

> 이 문서는 코드보다 우선한다. 전략이 바뀌면 먼저 이 문서를 고치고, 그 다음 코드를 맞춘다.

## 1. 운용 목표

- **목적**: 실질 수익 창출. 취미성 트레이딩이 아니라 규율 기반 자산 운용.
- **초기 운용금**: 300만~1,000만원. 단, **극소액(10~30만원)으로 Phase 3 실매매 검증** 통과 후 단계적 증액.
- **월 기대 수익률 기준선**: +5~10% (연 60~120%+). 공격적 목표치로, 백테스트 미검증 상태에서 이 구간을 이미 달성 중이라면 과적합·운을 먼저 의심한다.
- **허용 손실 상한 (MDD)**: 연 -15%, 월 -5%, **주 -3%**. 주간 임계치가 가장 먼저 선제 경보로 작동하며, 월·연 상한 도달 시 Kill Switch 발동 → 전략 재검증.

## 2. 매매 스타일 프로파일 (설정으로 전환)

사용자가 **설정에서 단일 프로파일을 선택**한다. 선택된 프로파일이 지표 타임프레임·주문 한도·손절폭·평가 주기 등을 결정한다. 기본값은 `swing`.

| 프로파일 | 보유 기간 | 주 타임프레임 | 기본 손절 | 기본 익절 | 1회 포지션 상한 | 권장 자금 대비 |
|----------|-----------|----------------|-----------|-----------|----------------|----------------|
| `scalp` | 수분~수시간 | 1m / 5m | -0.5% | +1% | 5% | 비추천 (레이트 리밋·감정 부담) |
| `day` | 당일 청산 | 5m / 15m / 1h | -1.5% | +3% | 7% | 고빈도 모니터링 가능 시 |
| **`swing` (기본)** | 수일~수주 | 1h / 4h / 1d | **-3%** | **+6%** | **10%** | 직장 병행에 적합 |
| `position` | 수주~수개월 | 1d / 1w | -8% | +20% 또는 시그널 | 20% | 장기 펀더멘털 근거 있을 때 |
| `dca` | 무기한 적립 | 해당 없음 | 없음(분할매수 전용) | 목표 수익률 달성 시 | 1회 3%, 월 누적 상한 별도 | 현금흐름 있는 월적립 |

**프로파일 전환 규칙**
- 전환 시 기존 보유 포지션은 이전 프로파일 규칙으로 청산 완료까지 유지
- 전환 후 최소 2주는 바꾸지 않는다 (잦은 변경은 전략 공백의 신호)

### 설정 저장
- **단기**: 환경변수 `DEFAULT_TRADING_STYLE` (.env)
- **Phase 5+**: DB `settings` 또는 `strategy_profiles` 테이블로 이관해 UI에서 토글

## 3. 대상 자산

- **화이트리스트(초기)**: `KRW-BTC`, `KRW-ETH`
- **확장 후보**: `KRW-XRP`, `KRW-SOL` — 단, 편입 전 아래 기준 충족
  - 시가총액 기준 글로벌 Top 20
  - 국내 거래량 충분 (일 거래대금 100억 이상)
  - 1년 이상 가격 이력 존재
- `ALLOWED_SYMBOLS` 환경변수로 강제 — 이 목록 밖 심볼은 safety 레이어가 즉시 거부
- 잡코인·미확인 알트·거래소 상폐 임박 종목은 영구 제외
- **상장폐지 종목 매수 절대 금지**: 상장폐지가 예정·진행·완료된 종목은 어떠한 경우에도 매수하지 않는다. 투자유의 종목 지정, 거래정지, 공식 상폐 공지 중 하나라도 해당하면 즉시 `ALLOWED_SYMBOLS`에서 제거하고 보유 중이라면 즉시 청산한다.

## 4. 매매 결정의 단계적 진화

자동화는 **검증된 단계를 지나야만 다음 단계로** 넘어간다.

```
Stage 1 (현재)   : 수동 분석·수동 주문
  ↓ DRY_RUN 통과 → D1 검증 3h(실주문 3회) + 파일럿 3h(실주문 5회) + 변동폭 가드 가동 확인
Stage 2          : 시그널 알림 (지표 자동 계산, 진입 판단은 사람)
  ↓ 1일(D2) 시그널 15회 관찰 + 백테스트 vs 라이브 예측 일치도 ±10% 이내
Stage 3          : 반자동 (시그널 발생 → 사용자 승인 → 자동 주문)
  ↓ 승인-주문 10회 + 오발동 0건 (D3 완료 즉시)
Stage 4          : 전면 자동 (사전 승인된 전략만, 일일 주문 한도·전략별 MDD 모니터 필수)
```

> **자산 클래스 프로파일로 절차 변형 가능**
> 암호화폐는 `ASSET_PROFILE_CRYPTO_SKIP_VERIFY=auto`(기본) 상태에서 첫 라이브 주문 1회 성공 후 자동으로 검증 단계 스킵 → Stage 1에서 바로 파일럿 진입. 주식(KIS)은 기본 `false`로 기존 절차 유지. 상세: [`docs/pilot-compression-plan.md` §9](pilot-compression-plan.md).

**Stage 진입 체크리스트** (각 단계 공통)
- [ ] 이전 단계 최소 운용 조건 충족 중 Critical 결함 0건
  - 1→2: D1 검증 3h(실주문 3회 체결·DB 기록 0건 누락) + 파일럿 3h(실주문 5회 + DAILY 경계 1회 접촉) + 변동폭 가드 정상 가동 확인
  - 2→3: D2 시그널 15회 관찰 + 백테스트 vs 라이브 예측 일치도 ±10% 이내
  - 3→4: D3 승인-주문 10회 + 오발동 0건
- [ ] 백테스트 vs 라이브 성과 괴리 ±10% 이내
- [ ] qa가 safety 레이어 회귀 테스트 통과
- [ ] 사용자 본인이 해당 단계 원칙을 문서화해 재확인
- [ ] analyst가 직전 단계 운용 데이터로 상태 분석 리포트 제출 (시그널 품질·손익 귀속·괴리 분석)
- [ ] analyst가 다음 단계 진입 시 적용할 리스크 제한·모니터링 지표를 설계하여 leader에게 전달

## 5. 포지션 사이징·자금 관리

- **1회 포지션 ≤ 계좌 총 자금의 10%** (swing 기준, 프로파일 표 참조)
- **심볼당 최대 포지션 ≤ 30%** — 분할매수해도 총 노출 상한 준수
- **잔고의 최소 10%는 현금 유지** — 급락 시 추가매수·손실 흡수 여력
- **분할매수**: 진입 의도 금액을 2~3회로 나누어 -2%/-4% 간격으로 분할 (스윙 기본)
- **분할매도**: 익절도 +3%/+6%/+10% 구간에서 1/3씩 정리

### 초기 주문 한도 권장값 (300만~1천만 운용 기준)

| 구간 | `ORDER_MAX_KRW` | `DAILY_ORDER_MAX_KRW` | 조건 |
|------|-----------------|------------------------|------|
| 검증 수동 (D1 09~12, 3h) | 10,000 | 50,000 | 체결 3회 + DB 기록·API 응답 0건 누락 |
| 파일럿 수동 (D1 13~16, 3h) | 50,000 | 300,000 | 체결 5회 + DAILY 경계 1회 이상 접촉 |
| Stage 2+ (D2~) | 300,000 | 1,500,000 | 파일럿 통과 즉시 적용 |

## 6. 손절·익절 원칙

- **모든 포지션은 진입 시점에 손절가·익절가를 같이 기록**한다 (`signals` 또는 포지션 테이블)
- 손절선은 **프로파일 기본값에서 개별 조정 가능**하되, 기본값 대비 2배 초과 금지 (swing 기본 -3% → 최대 -6%)
- 손절가 도달 시 **감정 개입 금지** — 자동화가 없어도 즉시 수동 청산
- 익절은 분할 정리로 평균 익절가를 확보 (목표 수익률 실현 후에도 일부 러너 유지 허용)

## 7. Kill Switch 발동 조건

아래 중 하나 충족 시 `KILL_SWITCH=true`로 전환 → 상황 리뷰 → 재개.

- 1일 손실이 계좌 잔고의 5% 초과
- 같은 전략에서 연속 5회 손절
- 거래소 API 에러율 10% 초과 (10분 창)
- `ALLOWED_SYMBOLS` 외 심볼이 `orders`에 등장 — 화이트리스트 우회 시도 의심
- 백테스트 vs 라이브 성과 괴리 ±20% 초과
- **변동폭 가드 블록** 발동: 포트폴리오 1h -4% / 6h -8% / 24h -12% 중 하나 이상 — `KILL_SWITCH` 자동 설정 (신규 주문 차단, 기존 포지션 유지. 수동 해제 필요. `VOL_GUARD_BLOCK_*` 환경변수로 임계치 조정 가능)
- **변동폭 가드 패닉** 발동: 포트폴리오 1h -7% / 6h -12% / 24h -18% 중 하나 이상 — 전 포지션 50% 시장가 매도 + `KILL_SWITCH` 동시 설정
- **단일 심볼 급락**: 개별 심볼 1h -10% 초과(BTC 1.0x, ETH 1.3x 배율 적용) → 해당 심볼 포지션 50% 청산 + 해당 심볼 신규 주문 차단
- **자동 주문 폭주**: 동일 전략에서 1분 이내 주문 시도 5회 이상 — 전략 엔진 오동작 의심

## 8. 성과 평가 지표

단일 지표로 판단하지 않는다. 아래를 **함께** 본다.

| 지표 | 기준선 | 의미 |
|------|--------|------|
| 연환산 수익률 | > 시장 수익률(BTC 보유 단순 수익률) | 알파 존재 여부 |
| 샤프비율 | > 0.8 | 변동성 대비 수익 |
| MDD | > -15% | 최악의 드로다운 |
| 승률 | 참고 지표 (>50%일 필요 없음) | 손익비와 함께 해석 |
| 손익비 (Avg Win / Avg Loss) | > 1.5 | 수익 거래가 손실 거래보다 커야 |
| 거래당 평균 수수료 비중 | < 10% | 고빈도 전략의 함정 탐지 |
| 변동폭 가드 경고 발동 | 월 3회 이하 권장 | 전략·포지션 사이징 변동성 점검 신호 |
| 변동폭 가드 블록 발동 | 월 1회 이하 | 발동 시마다 임계치·전략 재검토 필요 |
| 변동폭 가드 패닉 발동 | 0회 목표 | 발동 즉시 전략 중단 후 원인 분석 |
| 블록 해제 평균 소요 시간 | < 4시간 | 수동 리뷰 응답성 지표 |

## 9. 1차 전략 후보 (Phase 4~5에서 구체화)

스윙 프로파일 기준. analyst가 Phase 4에서 파라미터·백테스트·평가 완료 후 leader가 Stage 3 진입 여부 결정.

1. **이동평균 골든크로스 (MA-Cross)**
   - 4h 기준 EMA(20) > EMA(60) 전환 시 매수, 반대 전환 시 청산
   - 추세 추종 — 장기 상승장에 유리, 횡보장에 취약
2. **RSI 역추세 (RSI-Reversal)**
   - 1h 기준 RSI(14) < 30 & 직전 봉 대비 반등 시 분할매수
   - 과매도 반등 — 저점 매집 유리, 하락 추세에서는 칼날 잡기 위험
3. **볼린저 밴드 돌파 (Bollinger-Breakout)**
   - 1d 기준 종가가 상단 밴드 돌파 + 거래량 평균의 2배 시 매수, 중앙선 이탈 시 청산
   - 변동성 확대 구간 포착 — 폭등 초입 수익 가능, 페이크 브레이크아웃 비용

각 전략은 **독립적으로 백테스트** → 수익성 + 샤프·MDD 검증 → Stage 2(시그널 알림)에서 실제 시장 반응 대조 → Stage 3+로 승격.

## 10. 금기 사항

- **상장폐지 예정·진행·완료 종목 매수 금지** — 투자유의 지정·거래정지·공식 공지 중 하나라도 해당하면 즉시 화이트리스트에서 제거
- safety 레이어 우회 코드 금지 (`submitOrder()` 외 경로 금지)
- 백테스트 미검증 전략의 Stage 3+ 운용 금지
- 손절가 도달 시 "조금만 더 기다려본다" 금지 — 규칙 위반은 1회라도 기록·리뷰
- `.env` 실제 키를 커밋하거나 로그에 남기는 것 금지
- 프로파일 빈번 변경 (2주 내 2회 이상) 금지
- 단일 포지션에 계좌의 30% 초과 투입 금지 (분할매수라도)
- 레버리지·마진·선물 금지 (현 프로젝트 범위)
