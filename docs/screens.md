# 전체 화면·기능 지도

> StockInvest 웹앱 전체 화면·기능의 단일 진실 문서(Source of Truth).
> 모든 UI 구현은 이 문서를 참조하고, 변경이 필요하면 문서를 먼저 고친 뒤 코드를 맞춘다.

주 사용 환경: **갤럭시 S25+ + 크롬 모바일** (폭 ~412px). 모바일 우선 원칙은 [`.claude/agents/developer.md`](../.claude/agents/developer.md) "화면 디자인 워크플로우" 참조.

## 1. 네비게이션 구조

### 하단 4-탭 고정 바

| 탭 | 경로 | 아이콘 | 주 진입점 |
|----|------|--------|-----------|
| 🏠 대시보드 | `/` | home | 포트폴리오 요약·시세·차트 |
| 🎯 전략 | `/strategy` | target | 전략 목록·시그널·진행 중 주문 |
| 📈 분석 | `/analytics` | trending-up | 수익률·거래 이력·백테스트·로그 |
| ⚙️ 설정 | `/settings` | sliders | 프로파일·안전장치·계정 |

> **주문 탭 제거 (2026-04-19)**: 시그널 자동매매 전환 후 수동 주문 폼과 "진행 중 주문" 탭의 존재 이유가 사라짐. 주문 관련 기능을 의미적으로 연관된 탭으로 재배치. `/order` 경로는 `/strategy`로 redirect.

- 하단 바 높이 56~60px. 현재 탭은 배경 강조 + 아이콘/라벨 색상 변경
- `padding-bottom: env(safe-area-inset-bottom)` 적용해 홈 인디케이터 피함
- 탭 전환은 현재 스택 유지 (탭 재진입 시 마지막 화면 복원)

### 화면 영역 순서 (세로 스택)

```
[상단 컨텐츠 영역 — 탭별 주 화면]

[safety 토글 (44px, 필요 시 펼침)]   ← 대시보드·주문 등 위험 영역 탭에서만
[하단 5-탭 고정 바 (56~60px)]
```

## 2. 탭별 화면 카탈로그

### 🏠 대시보드 (`/`)

**주 화면**: 자동매매 운영 중심 구성. 구현 v1.

- 상단 요약: 총 자산 KRW / 24h 변동 / 현금 비중 / 마지막 업데이트 / 새로고침 (자동 30초 새로고침)
- **자동매매 상태 카드**: 활성 전략 · 오늘 시그널 · 오늘 체결 (Phase 3~5) · **포트폴리오 오늘** (오늘 00:00 KST 대비 현재 가치 변동, `today_change_pct`/`today_change_krw`. 데이터 없으면 "준비 중")
- **최근 체결 타임라인** (Phase 3 연결): 매매 이력 시간순, 각 행에 체결 후 현재 손익 표시
- 보유/관심 탭 + 리스트 — 각 행 우측 하단에 매수·매도 인라인 버튼 (화이트리스트 심볼 한정)
- 차트 섹션 (하위 순위): 심볼 chip 스와이프 + 인터벌 토글 + 캔들 차트 + 24h 고/저/거래량 KPI
- safety 토글 (접힘 기본)

**서브 화면**: 없음. 진입은 전부 다른 탭으로.

### 🎯 전략 (`/strategy`)

**주 화면 — 분석가 운영 현황**
- AnalystStatusBanner: Kill Switch 상태·Analyst ON/OFF 토글
- AI 판정 이력 (SignalDecisionLog): 자동 제출/스킵 시그널 최근 50건
- 전략 관리 (접힘 기본): 전략 카드 + ON/OFF 토글 + 백테스트 상태
- **⚡ 진행 중 주문 섹션** (하단 고정): 자동매매로 생성된 pending/accepted/partially_filled 주문. 건수 > 0 시 빨간 뱃지. 0건이면 "🤖 진행 중 없음 — 자동매매 대기 중" 표시. 주문 클릭 → OrderDetail 바텀 시트 (시그널 연결 정보 포함)

**서브 화면**
- `/strategy/:id` — 전략 상세: 진입·청산 규칙·파라미터·최근 백테스트 요약. 편집 가능
- `/strategy/signals` — 시그널 피드: 최근 발행 시그널 시간순, 연결된 주문 링크
- `/strategy/approvals` — 승인 대기 큐 (Stage 3): 미처리 시그널 + 승인/거부 버튼

### 📈 분석 (`/analytics`)

**주 화면 — 수익률 대시**
- 기간 토글: D / W / M / Y
- 누적 수익률 차트
- 핵심 지표: 승률 / 샤프 / MDD / 손익비 / 거래 건수

**서브 탭**
- **거래 이력** (기본): 오늘 요약 바 (체결/DRY_RUN/차단 건수) + 날짜 구분 주문 목록. 주문 카드에 소스 뱃지([자동]/[시그널]/[수동]) + 시그널 reasoning 미리보기. 클릭 → OrderDetail 바텀 시트 (시그널 연결 섹션 포함). 필터: 전체/체결/DRY_RUN/차단/실패·거부
- 포트폴리오: 기간별 수익률·자산 구성
- 전략 성과: 전략별 백테스트 지표·시그널 통계
- 거래 로그: `trade_logs` 시간순 이벤트

**서브 화면**
- `/analytics/backtest` — 백테스트 실행: 전략·기간·초기 자본·수수료·슬리피지 선택 → 실행 진행률 표시
- `/analytics/backtest/:id` — 결과: 에쿼티 커브 / 거래 리스트 / 지표 요약 / **라이브 vs 백테스트 괴리**
- `/analytics/volatility-guard` — 변동폭 가드 이력: 경고·블록·패닉 발동 기록 (타임스탬프·지표 값·액션)
- `/analytics/audit` — 감사 로그: `trade_logs` 시간순 스크롤. 필터(이벤트 타입·심볼·주문 id). 각 로그 탭 시 주문 상세로 이동 가능
- `/analytics/snapshots` — 포트폴리오 스냅샷 추이: `portfolio_snapshots` 기반 시계열 (V0.3)

### ⚙️ 설정 (`/settings`)

**주 화면 — 설정 허브**
섹션별 카드 또는 리스트로 구성:
- 자산 프로파일
- 안전장치
- 변동폭 가드 임계치
- 거래소 계정
- 알림
- 지표 기본값
- 데이터 관리
- 앱 정보·버전

**서브 화면 (각 섹션 상세)**
- `/settings/profile` — 자산 프로파일
  - 매매 스타일: scalp / day / swing / position / dca (현재 활성 하나만, 2주 내 재변경 경고)
  - 검증 스킵: crypto / stock 별로 auto / on / off
- `/settings/safety` — 안전장치
  - DRY_RUN 토글 (변경 시 재확인)
  - KILL_SWITCH 토글
  - ORDER_MAX_KRW 숫자 입력
  - DAILY_ORDER_MAX_KRW 숫자 입력
  - ALLOWED_SYMBOLS 멀티셀렉트
- `/settings/vol-guard` — 변동폭 가드: 1h/6h/24h × 경고/블록/패닉 % + 심볼별 배율
- `/settings/exchanges` — 거래소 계정: 코인원(연결 상태, 키 테스트), 업비트(확장 예정), KIS(Phase 7)
- `/settings/notifications` — 알림 채널 on/off: 가격·시그널·체결·안전장치
- `/settings/indicators` — 지표 기본값: RSI 기간, MA 기간, MACD 파라미터 등
- `/settings/data` — portfolio_snapshots·trade_logs 보존 기간, 수동 백업
- `/settings/about` — 앱 버전·Phase 진행 현황·문서 링크

## 4. 화면 간 이동·공용 컴포넌트

### 이동 경로 (주요)

- 전략 상세 → 분석 백테스트: `/analytics/backtest?strategy=<id>`
- 백테스트 결과 → 전략 상세: `/strategy/:id` (결과 반영 후 돌아감)
- 전략 탭 "진행 중 주문" → OrderDetail 바텀 시트 (시트 내에서 취소 가능)
- 분석 탭 "거래 이력" → OrderDetail 바텀 시트 (시그널 연결 정보 포함)
- 시그널 피드 → OrderDetail 바텀 시트 (`consumed_order_id` 기준 조회)
- 설정 허브 ↔ 각 세부 설정 페이지
- `/order` → 301 redirect → `/strategy`

### 공용 컴포넌트 (Phase 2+ 공통 구축 대상)

| 컴포넌트 | 역할 | 사용 처 |
|----------|------|---------|
| `SymbolPicker` | 심볼 선택 (화이트리스트 필터 옵션) | 대시보드 chip, 주문 폼, 전략 상세 |
| `IntervalToggle` | 타임프레임 토글 (1h/4h/1d 기본) | 대시보드, 지표 설정 |
| `SafetyBar` | 하단 safety 토글 바 | 대시보드, 주문, 전략 |
| `BottomTabs` | 하단 4-탭 고정 네비 | 모든 페이지 공통 레이아웃 |
| `PriceInput` | 가격 입력 + tabular-nums | 주문 폼, 설정 |
| `QtyInput` | 수량/KRW 입력 + 환산 | 주문 폼 |
| `NumFmt` | 숫자 포맷터 (`ko-KR` locale) | 전체 |
| `PnlChip` | 손익 색상 칩 (상승 빨강·하락 파랑) | 대시보드, 주문 이력, 분석 |
| `EmptyState` | 데이터 없음 placeholder | 이력·로그 화면 |
| `ConfirmDialog` | 2차 확인 (실주문·Kill Switch 해제 등) | 주문 제출, 설정 변경 |

## 5. 미해결·후속 결정

- **알림 채널**: 푸시(웹 Push API) vs 이메일 vs 슬랙 — 어느 것부터 구현?
- **설정 저장소**: 현재 환경변수, Phase 5+에 DB `settings` 테이블로 이관. 이관 시 UI에서 즉시 반영 방식(마이그레이션 스크립트) 결정 필요
- **라이트 테마**: 현재 다크만. OS 설정 연동으로 라이트 테마 지원 여부
- **다국어**: 한국어만. 영어 지원은 고려 안 함 (1인 운용)
- **서브화면 깊이**: 각 탭 스택을 2~3 depth 이상 가지 않도록 제한 — 지금은 대부분 2 depth로 계획
