# 전체 화면·기능 지도

> StockInvest 웹앱 전체 화면·기능의 단일 진실 문서(Source of Truth).
> 모든 UI 구현은 이 문서를 참조하고, 변경이 필요하면 문서를 먼저 고친 뒤 코드를 맞춘다.

주 사용 환경: **갤럭시 S25+ + 크롬 모바일** (폭 ~412px). 모바일 우선 원칙은 [`.claude/agents/developer.md`](../.claude/agents/developer.md) "화면 디자인 워크플로우" 참조.

---

## 1. 네비게이션 구조

### 하단 5-탭 고정 바

| 탭 | 경로 | 아이콘 | 주 진입점 |
|----|------|--------|-----------|
| 🏠 대시보드 | `/` | home | 포트폴리오 요약·투자 현황·시세·차트 |
| 💡 추천 | `/recommend` | bulb | AI 시그널 승인 대기·시나리오 빌더 |
| 💬 채팅 | `/ai` | chat | AI 채팅 |
| 📈 분석 | `/analytics` | trending-up | 수익률·결정 이력·거래 이력·로그 |
| ⚙️ 설정 | `/settings` | sliders | 안전장치·거래소 계정·알림·LLM |

- 하단 바 높이 56~60px. 현재 탭은 배경 강조 + 아이콘/라벨 색상 변경
- `padding-bottom: env(safe-area-inset-bottom)` 적용해 홈 인디케이터 피함
- 탭 전환은 현재 스택 유지 (탭 재진입 시 마지막 화면 복원)

### 화면 영역 순서 (세로 스택)

```
[상단 컨텐츠 영역 — 탭별 주 화면]
[sticky 탭·필터 등 탭 고유 2차 내비 (선택)]
[메인 콘텐츠 (스크롤)]
[safety 토글 (44px, 필요 시 펼침)]   ← 대시보드·추천 등 위험 영역 탭에서만
[하단 5-탭 고정 바 (56~60px)]
```

## 2. 투자 워크플로우

```
전략 엔진 → 시그널 생성 (pending_approval)
  ↓ 💡 추천 탭: 사용자 검토
  ├─ [승인] → approved_pending_entry → entry-watcher (2~5분 주기)
  │             → 진입 구간 도달 → 주문 체결 → 포지션 → exit-engine → 청산
  ├─ [거절] → rejected (놓친 기회 탭에 기록)
  └─ TTL 만료 → expired
```

## 3. 탭별 화면 카탈로그

### 🏠 대시보드 (`/`)

**주 화면**: 사용자 개입형 투자 관리 중심 구성.

- 상단 요약: 총 자산 KRW / 24h 변동 / 현금 비중 / 마지막 업데이트 / 새로고침 (자동 30초 새로고침)
- **투자 현황 카드 (4-grid)**:
  - 승인 대기 N건
  - 진입 감시 중 N건
  - 오늘 체결 N건
  - 포트폴리오 오늘 (`today_change_pct` / `today_change_krw`. 데이터 없으면 "준비 중")
- **승인 대기 배너**: `pending_approval > 0` 시 amber 배너 → `/recommend` 링크
- **트레이딩 보드**: "승인 대기 → 진입 감시 → 포지션" 3단계 시각화
- **최근 주문**: 최근 주문 10건을 **날짜(1차) → 종목(2차)** 2단 그룹으로 표시
  - 날짜 구분 라벨: 오늘 / 어제 / `M. D.`
  - 종목 그룹 헤더(`<button aria-expanded>`, 최소 높이 44px): `국기 + 종목명(코드)` + `N건 · HH:MM~HH:MM`
    (1건이거나 시각이 같으면 범위 대신 단일 시각 `1건 · 10:05`)
  - 기본 **접힘**. 1건짜리 종목도 예외 없이 그룹으로 표시
  - 펼치면 기존 주문 행(매수/매도 뱃지 + 금액 + 상태 + 시각) 노출
  - 그룹 요약은 **"최근 10건" 범위 안에서의** 건수·시각범위다(그날 전체가 아님).
    그날 전체는 "전체 보기 →" → 분석 탭 거래 이력에서 확인
  - 이 범위 제한을 문서 없이도 알 수 있게 섹션 헤더에 **`· 최근 N건`** 보조 표기를 둔다.
    표기의 N은 표시 상수(`RECENT_LIMIT`)를 참조하므로 건수를 바꿔도 어긋나지 않는다
  - 종목명 표기는 `useSymbolMeta()`(`displaySymbol`/`marketFlag`)로 거래 이력과 통일
  - 헤더 "전체 보기 →" → `/analytics?tab=orders`
- 보유/관심 탭 + 리스트
- 차트 섹션: 심볼 chip 스와이프 + 인터벌 토글 + 캔들 차트 + 24h 고/저/거래량 KPI
- safety 토글 (접힘 기본)

**서브 화면**: 없음. 진입은 전부 다른 탭으로.

### 💡 추천 (`/recommend`)

**주 화면 — 사용자 승인 대기 시그널**

- **승인 대기 (pending_approval) 시그널 카드**:
  - 등급·EV·손익·리스크 표시
  - [상세→] 버튼 → ScenarioDetail 서브화면
  - [거절] 버튼 → 즉시 rejected 처리
- **진입 감시 중 (approved_pending_entry) 목록**: [취소] 버튼으로 승인 철회 가능
- **[내 시나리오 만들기]** → ScenarioBuilder

**서브 화면**

- ScenarioDetail: 진입구간·매매수치 편집 + [승인] / [거절] 버튼
- ScenarioBuilder: 방향 / 종목 / 분할 / 기간 → AI 분석 → 결과 확인 후 제출

### 📈 분석 (`/analytics`)

**주 화면 — 서브 탭 컨테이너**

서브 탭 목록:

| 탭 | 내용 |
|----|------|
| 포트폴리오 | 기간별 수익률 + 자산 구성 + 자산 추이 차트 |
| 내 결정 | 승인/거절/만료 시그널 이력 + 결과 추적 |
| 놓친 기회 | AI 스킵 + 사용자 거절 시그널 사후 가격 추적 |
| 거래 이력 | 날짜별 주문 목록 (필터: 체결/DRY_RUN/차단/실패) |
| 변동폭 | Vol Guard 상태 + 포트폴리오 추이 차트 |
| 전략 성과 | 전략별 백테스트 지표·시그널 통계 |
| 분석 이력 | 전략 엔진 시그널 이력 (auto_submitted/ai_skipped) |
| 신호 진단 | 시그널 품질 분석 |
| 거래 로그 | `trade_logs` 이벤트 스트림 |

**포트폴리오 서브탭 상세**
- 기간 토글: 1D / 7D / 30D
- 기간별 수익률 리스트
- 자산 추이 차트 (SVG 미니 라인, `portfolio_snapshots` 기반)
- 자산 구성 (포지션별 비중·평가금)

**놓친 기회 서브탭 상세**
- 요약 칩: 전체 / 놓친 기회(+3%↑) / 올바른 스킵(-3%↓) / 내 거절 기회(+3%↑)
- 출처 필터: 전체 / AI 스킵 / 내 거절
- 기간 필터: 1일 / 3일 / 7일 / 14일
- 시그널 카드: 출처 배지('내 거절') + 가격 정보 + AI 판단 이유

**거래 이력 서브탭 상세**
- 오늘 요약 바 (체결/DRY_RUN/차단 건수) — 필터·페이지와 무관하게 KST 오늘 전체 기준
- 필터: 전체/체결/DRY_RUN/차단/실패·거부
- **날짜(1차) → 종목(2차) 2단 그룹** 목록
  - 날짜 구분 라벨: 오늘 / 어제 / `M. D.`
  - 종목 그룹 헤더(`<button aria-expanded>`, 최소 높이 44px): `국기 + 종목명(코드)` + `N건 · HH:MM~HH:MM`
    (1건이거나 시각이 같으면 범위 대신 단일 시각 `1건 · 10:05`)
  - 기본 **접힘**. 1건짜리 종목도 예외 없이 그룹으로 표시
  - 펼치면 기존 주문 카드(소스 뱃지 [자동]/[시그널]/[수동] + 시그널 reasoning 미리보기) 그대로 노출
- **페이지 단위 = 날짜 그룹 5개** (주문 건수가 아님)
  - 🔴 정확성 요건: **필터 → 그룹핑 → 페이징** 순서를 반드시 지킨다.
    페이징을 그룹핑보다 먼저 하면 같은 날 같은 종목이 페이지 경계에서 쪼개져
    그룹 요약(건수·시각범위)이 실제와 다른 값을 표시한다
- 주문 카드 클릭 → OrderDetail 바텀 시트 (시그널 연결 섹션 포함)
- 데이터 방어: `created_at` 파싱 실패 → `(날짜 미상)` 그룹, `symbol` 결측 → `(알 수 없음)` 그룹.
  해당 주문을 조용히 버리지 않는다
- 그룹핑 로직은 순수 함수 `src/lib/orders/group-orders.ts`(`groupByDateThenSymbol`)에 있고
  대시보드 "최근 주문"과 공유한다

**서브 화면**
- `/analytics/backtest` — 백테스트 실행: 전략·기간·초기 자본·수수료·슬리피지 선택 → 실행 진행률 표시
- `/analytics/backtest/:id` — 결과: 에쿼티 커브 / 거래 리스트 / 지표 요약 / 라이브 vs 백테스트 괴리
- `/analytics/volatility-guard` — 변동폭 가드 이력: 경고·블록·패닉 발동 기록 (타임스탬프·지표 값·액션)
- `/analytics/audit` — 감사 로그: `trade_logs` 시간순 스크롤. 필터(이벤트 타입·심볼·주문 id)

### ⚙️ 설정 (`/settings`)

**주 화면 — 설정 허브**

섹션별 카드 또는 리스트로 구성:
- 안전장치
- 변동폭 가드 임계치
- 거래소 계정
- 알림
- LLM 설정
- 자산 프로파일
- 지표 기본값
- 데이터 관리
- 앱 정보·버전

**서브 화면 (각 섹션 상세)**
- `/settings/safety` — 안전장치
  - DRY_RUN 토글 (변경 시 재확인)
  - KILL_SWITCH 토글
  - ORDER_MAX_KRW 숫자 입력
  - DAILY_ORDER_MAX_KRW 숫자 입력
  - ALLOWED_SYMBOLS 멀티셀렉트
- `/settings/vol-guard` — 변동폭 가드: 1h/6h/24h × 경고/블록/패닉 % + 심볼별 배율
- `/settings/exchanges` — 거래소 계정: KIS(연결 상태·키 테스트), 코인원(확장 대상), 업비트(확장 대상)
- `/settings/notifications` — 알림 채널 on/off: 가격·시그널·체결·안전장치
- `/settings/profile` — 자산 프로파일
  - 매매 스타일: scalp / day / swing / position / dca
  - 검증 스킵: stock / crypto 별로 auto / on / off
- `/settings/indicators` — 지표 기본값: RSI 기간, MA 기간, MACD 파라미터 등
- `/settings/data` — `portfolio_snapshots`·`trade_logs` 보존 기간, 수동 백업
- `/settings/about` — 앱 버전·Phase 진행 현황·문서 링크

## 4. 화면 간 이동·공용 컴포넌트

### 이동 경로 (주요)

- 대시보드 "승인 대기 배너" → `/recommend`
- 추천 탭 "상세→" → ScenarioDetail (서브화면)
- 추천 탭 "[내 시나리오 만들기]" → ScenarioBuilder (서브화면)
- 분석 탭 "거래 이력" → OrderDetail 바텀 시트 (시그널 연결 정보 포함)
- 대시보드 "최근 주문 → 전체 보기" → `/analytics?tab=orders` (거래 이력 서브탭 직접 진입)
- 전략 백테스트 → `/analytics/backtest?strategy=<id>`
- 백테스트 결과 → 전략 상세 (결과 반영 후 돌아감)
- 설정 허브 ↔ 각 세부 설정 페이지

### 공용 컴포넌트

| 컴포넌트 | 역할 | 사용 처 |
|----------|------|---------|
| `SymbolPicker` | 심볼 선택 (화이트리스트 필터 옵션) | 대시보드 chip, 추천, 전략 상세 |
| `IntervalToggle` | 타임프레임 토글 (1h/4h/1d 기본) | 대시보드, 지표 설정 |
| `SafetyBar` | 하단 safety 토글 바 | 대시보드, 추천 |

| `QtyInput` | 수량/KRW 입력 + 환산 | ScenarioBuilder |
| `NumFmt` | 숫자 포맷터 (`ko-KR` locale) | 전체 |

| `OrderDetail` | 주문 상세 바텀 시트 (시그널 연결 섹션 포함) | 분석 거래 이력, 대시보드 |
| `SymbolGroupHeader` | 종목 그룹 접기/펼치기 헤더 (`aria-expanded` + 건수·시각범위 요약) | 분석 거래 이력, 대시보드 최근 주문 |

## 5. 미해결·후속 결정

- **알림 채널**: 푸시(웹 Push API) vs 이메일 vs 슬랙 — 어느 것부터 구현?
- **설정 저장소**: 현재 환경변수, Phase 5+에 DB `settings` 테이블로 이관. 이관 시 UI에서 즉시 반영 방식(마이그레이션 스크립트) 결정 필요
- **라이트 테마**: 현재 다크만. OS 설정 연동으로 라이트 테마 지원 여부
- **다국어**: 한국어만. 영어 지원은 고려 안 함 (1인 운용)
- **서브화면 깊이**: 각 탭 스택을 2~3 depth 이상 가지 않도록 제한 — 지금은 대부분 2 depth로 계획
- **놓친 기회 가격 추적**: 현재 1h 후 가격. 4h / 24h 추적 추가 여부
