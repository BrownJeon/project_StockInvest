A. 서버 연결 실패 화면 — public/app-shell/index.html (APK 안, 외부 자원 없음)

앱이 운영 서버를 불러오지 못했을 때만 보인다(Capacitor server.errorPath). 휴대폰 인터넷이 끊겼는지(navigator.onLine) 서버가 응답하지 않는지만 나눠 말하고, 할 수 있는 일(다시 시도·PC 로 확인)을 준다. 매매가 "안전하다"는 약속은 하지 않는다 — 서버가 멈춘 경우일 수도 있기 때문이다.

상태

모바일 — 연결 실패 화면 (화면 안 [다시 시도]도 눌러 볼 수 있다)

구현 메모

  • 한 파일 HTML, 인라인 CSS·JS 만(폰트·이미지·스크립트 외부 참조 0). 로고는 인라인 SVG.
  • 색은 globals.css 와 같은 이름의 변수(--bg --bg2 --border --text --muted --accent --warn)를 :root 에 hex 로 복사한다(서버에 못 닿는 화면이라 링크 불가). 파일 머리 주석에 "원본 globals.css sha256 앞 12자"를 남겨 어긋남을 찾게 한다.
  • 다크 한 벌만(앱이 다크 전용, themeColor #0f1115).
  • [다시 시도] = 운영 주소로 location.replace. 누르면 버튼이 "연결 중…"으로 잠기고 약 8초 뒤 풀린다(실패하면 Capacitor 가 이 화면을 다시 띄운다). 휴대폰이 다시 온라인이 되면(online 이벤트) 한 번 자동 시도. 주기적 자동 재시도는 하지 않는다(배터리·서버 부하).
  • 상태 문장은 aria-live="polite" 영역. 제목은 h1, 버튼 48px.
  • 이 파일을 바꾸면 네이티브 변경이다(APK 재빌드·versionCode 증가).
  • 데스크톱 복원 해당 없음 — 휴대폰 앱에서만 뜨는 화면.

B. 앱 업데이트 띠 — 앱 안에서만, 화면 맨 위 (AppUpdateBanner)

웹 브라우저에서는 그리지 않는다(요청도 하지 않음). 로그인 뒤 버전 조회(GET /api/app/version)가 "내 versionCode < 최신"이면 새 버전 안내, "< 최소 지원"이면 필수 업데이트. 둘 다 화면을 덮지 않고 문서 흐름 맨 위에 끼워 넣는 띠다 — 스크롤하면 지나가고, 아래 화면(비상 청산·승인 버튼·안전장치 표시)은 그대로 누를 수 있다. 화면 안 띠의 [받기]·✕·글자를 눌러 보라.

상태·동작 표

  • 숨김: 웹 · 앱 정보 없음 · 조회 실패(조용히 숨김, 오류 띠를 따로 띄우지 않음) · 최신. 로그인 화면 등 인증 전 화면(BottomTabs 의 HIDDEN_PATHS)에서도 숨김 — 버전 조회가 로그인 필요라 알 수 없다.
  • 조회 시점: 첫 진입 1회 + 앱이 다시 앞으로 올 때 마지막 확인이 6시간 넘었으면 다시(TheKaiwa 와 같음).
  • 안전영역: 띠가 페이지 맨 위 요소이므로 padding-top: var(--safe-top) 를 띠가 가진다(edge-to-edge 'auto' 여백이 들어가면 0 일 가능성이 높음 — 실기기 확인).
  • role="status"(필수도 status — 화면 이동마다 alert 가 반복 낭독되지 않게). 버튼·✕ 44px.
  • 데스크톱 복원 해당 없음 — 앱 안에서만 뜬다.

C. 앱 설치·업데이트 안내 — 기존 설정 탭 맨 아래 "앱" 섹션 (새 라우트 없음)

설정 화면의 기존 섹션(내 계정 · 자산 기록 · 승인 방식 · 안전장치 … · 정기 거래 리포트) 순서는 그대로 두고, 맨 아래 안내 상자 바로 위에 앱 (안드로이드) 섹션 하나를 더한다(id="app" — 업데이트 띠가 여기로 보낸다). 같은 섹션이 웹 브라우저에서는 설치 안내, 앱 안에서는 버전·업데이트를 보인다. 새 페이지 대신 섹션을 권하는 이유는 D4.

D. 로그인 화면 앱 분기 — 현재(웹) vs 제안(앱)

현재 src/app/login/page.tsx + AuthShell + OAuthButtons 구조 그대로다. 앱에서는 Google/GitHub 버튼과 "또는 이메일로" 구분선이 통째로 사라진다(OAuthButtons 가 앱이면 null — 회원가입 화면도 같은 컴포넌트라 함께 처리됨). 나머지(제목·이메일·비밀번호·회원가입·가입 요청·30일 안내)는 같다. 웹 화면은 바뀌지 않는다.

오류 상태

웹 브라우저 — 현재 그대로 (변경 없음)

앱 — 제안 (OAuth 버튼·구분선 없음)

⚠ 발견: 소셜 전용 계정이 앱에서 로그인하면 서버가 "아래 Google로 계속하기를 눌러 로그인하세요"를 돌려준다 — 앱에는 그 버튼이 없어 막다른 문구가 된다. 앱 분기에서는 error === 'oauth_account' 일 때 앱용 문구로 바꿔 보인다(서버 응답은 그대로). 소셜 전용 계정은 비밀번호를 만들 수도 없어(/api/profile/password 가 거부) 앱 로그인 자체가 불가능하다 — D7.

데스크톱: 로그인은 가운데 카드(최대 380px)라 넓은 화면에서도 같은 모양이다 — 바뀌는 것 없음.

E. 앱 아이콘 시안 3종 + 스플래시 — "주식캐기"

안드로이드 적응형 아이콘: 108dp 레이어 중 런처가 보이는 곳은 가운데 72dp, 어떤 마스크에서도 잘리지 않는 곳은 지름 66dp 원(점선). 전경은 그 원 안에만 그렸다. 배경은 앱 다크(--bg2) + 땅 층(--bg3 · --bg4, "캐는" 느낌). 금색은 --accent(금 = 캐낸 것), 오르는 것은 한국 관습 --up 빨강.

보조선

A. 곡괭이 + 오르는 캔들 ✓ 권장

이름의 "캐기"를 그대로 그림으로 — 곡괭이(금색 머리)가 빨간 상승 캔들 옆을 찍는다. 48px 에서도 곡괭이 머리와 캔들 두 덩어리로 읽힌다. 한계: 요소가 둘이라 B 보다 조금 복잡.

B. 금맥 차트 + 금덩이

오르는 선이 금덩이에 닿는다(캐낸 결과). 모양이 가장 단순해 작은 크기에 강하다. 한계: "곡괭이"가 없어 이름의 익살은 약하고, 흔한 주식 앱 아이콘과 비슷해 보일 수 있다.

C. 글자 마크 "캐"

금색 "캐" + 빨간 ▲. 한글 이름과 바로 연결되고 그리기 쉽다. 한계: 글자 아이콘은 뜻(주식)이 안 보이고, 최종 파일은 글꼴이 아니라 윤곽선으로 바꿔야 한다(이 데모는 기기 글꼴로 그림).

모바일 — 스플래시 (아이콘 A + 이름)

주식캐기주식 자동매매

스플래시·아이콘 구현 메모

  • 배경 --bg(#0f1115 = themeColor) — 스플래시 → 웹 화면 전환 때 색이 튀지 않는다.
  • [가능성 높음] 안드로이드 12+ 는 시스템 스플래시가 아이콘만 가운데에 그린다. 이름은 하단 "브랜딩 이미지"(windowSplashScreenBrandingImage)로 넣어야 하고, 지원 안 되는 기기에서는 이름 없이 아이콘만 보일 수 있다 — 실기기 확인 항목.
  • 아이콘 최종 산출: ic_launcher_foreground(전경 벡터) + ic_launcher_background(배경색/벡터) + 안드로이드 13 테마 아이콘용 monochrome(전경 한 색). 글자(C안)는 윤곽선 변환 필수.
  • 표시 이름 "주식캐기"(4자) — 홈 화면 라벨에서 잘리지 않는다.

D7. 소셜 전용 계정 (앱 로그인 불가) — Leader 확인 필요

B. A + 설정 › 앱(웹 보기)에 "이 계정은 앱에서 로그인할 수 없습니다" 경고

설치 전에 미리 안다(데모 '소셜 전용 계정' 상태).
한계: 현재 사용자의 비밀번호 유무를 내려 주는 API 필드가 필요 — 사양은 Leader 판단. 운영 계정이 소셜 전용이면 B 가 아니라 M1 범위 자체(앱 로그인 방법)를 다시 정해야 한다.

설계 메모

  • 안전 표시 우선: 새 요소 어느 것도 화면을 덮지 않는다. 띠는 흐름 안, 연결 실패 화면은 서버를 못 불러올 때만, 설정 섹션은 맨 아래. 안전장치·주문·승인 화면 코드는 바꾸지 않는다.
  • 거짓 안심 금지: 연결 실패 화면은 "매매는 안전합니다" 같은 말을 하지 않는다(서버가 멈춘 경우일 수 있음). "주문·승인은 서버에 연결된 뒤에만 할 수 있습니다"만 적는다.
  • 색: 금색(--accent)은 행동 버튼·새 버전 막대, 빨강 톤은 필수 업데이트·오류(기존 noteDanger 값 재사용), 빨강·파랑 손익 색은 아이콘의 상승 캔들 외에는 쓰지 않는다. 모든 상태는 기호+글자를 함께 쓴다.
  • 앱 판별은 화면 표시만: 앱/웹 분기는 버튼 숨김·띠 표시에만 쓰고 서버 권한 판단에 쓰지 않는다. 웹 번들은 @capacitor/* 를 import 하지 않고 window.Capacitor 전역만 본다.
  • 깜빡임: OAuthButtons 는 원래 목록을 받기 전까지 아무것도 그리지 않으므로, 앱 판별을 그 전에 하면 앱에서 버튼이 잠깐 보였다 사라지는 일이 없다.
  • 360px: 띠 첫 줄은 "주식캐기 v버전"만(말줄임돼도 버전이 앞), 설정 앱 줄은 줄바꿈 허용, 확인값은 8자만. 가로 스크롤 0.
