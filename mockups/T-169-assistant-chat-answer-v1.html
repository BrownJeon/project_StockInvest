비서 답변을 대화형 문장으로 — 답변 텍스트 규격

T-169 · 데모 v1 (delta) · 화면 배치·컴포넌트는 그대로이고, 말풍선 안 글만 바뀝니다.

답변 예시 — 실제 모델 출력 아님, 투자 권유 아님. 「변경 후」 말풍선은 이 규격으로 답하면 이런 모양이라는 예시 글입니다. 종목·수치는 운영 DB 를 읽기 전용으로 조회한 값(기준 시각 표기)이고, 일봉으로 계산한 지표는 대략치입니다. 「현재」 말풍선은 운영 DB 에 실제 저장된 답 그대로입니다.

무엇이 바뀌나

  • 지금: 비서 답이 매매 판정용 JSON(selectedIndices·confidence…)으로 나옵니다. 운영 기록상 홈서버 모델 답 15건이 모두 이 모양이었습니다.
  • 변경 후: 일반 대화 문장으로 답하고, 질문에 종목이 없어도 시스템이 모은 데이터(경제 흐름·엔진 최근 후보·지표·뉴스 제목)를 근거로 씁니다.
  • 예전에 저장된 JSON 답은 지우지 않고, 볼 때만 문장으로 바꿔 보여 줍니다(장면 ④).

답의 구조 규칙

  1. 핵심 답 첫 문장에서 질문에 바로 답한다.
  2. 근거·기준 시각 첨부된 수치만 쓰고, 언제 값인지 「(11-14 05:55 기준)」처럼 붙인다. 없는 자료는 한 문장으로 밝히고 있는 자료로 답한다.
  3. 검토 후보 종목마다 근거 1~2개와 위험 1개. 「지금 사라」 같은 단정은 쓰지 않는다.
  4. 참고용 고지 끝에 한 줄 — 이 시스템의 검증된 전략 판정이 아니라 참고용.

형식: 화면이 글자를 그대로 보여 주므로(pre-wrap, 마크다운 해석 없음) 짧은 문단과 1.·- 목록만 쓴다. **·#·표·JSON·코드블록은 쓰지 않는다.

안내선(점선·이름표)은 데모에서 규칙을 보이려고 덧그린 것입니다. 「실제 화면처럼」을 누르면 사용자가 볼 모양 그대로입니다.

결정 필요

고르면 미리보기가 바로 바뀝니다. 권고는 디자이너 의견입니다.

D1. 추천 질문에 후보를 몇 개까지 자세히 쓸까

권고 A [가능성 높음] — 사용자가 「5개」라고 콕 집어 물었으므로 그대로 답하는 쪽이 맞다. 대신 종목당 세 줄(이름·근거·위험)로 줄였다. 412px 실측: A 766자 · 말풍선 600px 로 메시지 영역(622px)과 거의 같은 높이, B 654자 · 532px — 차이가 크지 않다. 어느 쪽이든 질문 말풍선까지 함께 보려면 한 번 스크롤한다. 장면 ①에 적용.

D2. 예전 JSON 답을 문장으로 바꿔 보일 때 표시할까

권고 B [가능성 높음] — 저장된 원문과 화면 글이 달라지므로 그 사실을 한 줄로 밝히는 편이 오해가 적다. 화면 요소는 늘지 않고 글 한 줄만 붙는다. 장면 ④에 적용.

D3. 경제 흐름 요약에 「다음 금리 결정일·물가 기준월」도 넣을까

권고 A [가능성 높음] — 이 값은 이미 같은 기록 행에 있다(다음 결정일 12-09). 빼면 모델이 「다음 주에 회의가 있다」는 질문의 전제를 확인하지 못한다. 장면 ③에 적용. 단, 경제 흐름 자료를 채팅에 쓰는 것 자체가 Leader 확인 사항이다(아래 메모 1).

  • 1) 경제 흐름 기록을 채팅 요약에 쓰는 것 — src/lib/strategy/macro-regime/types.ts 머리 주석이 「AI 프롬프트에는 쓰이지 않는다」, 의존 경계 시험 주석이 「C1 프롬프트 승격은 별 task」라고 적는다. 표를 직접 SELECT 하면 시험(모듈 import 검사)은 통과하지만 그 의도와 맞는지 Leader·analyst 판단이 필요하다. 라벨 한국어 표기 코드도 없다(이 데모는 「보통·긴축」으로 적었다).

  • 3) signals.price 는 해외도 원화 환산값이다. 달러 표기는 일봉 종가나 paper_fills.limit_price(USD)에서 가져와야 한다. MCHP 는 일봉 종가 $62.25 와 신호 시점 $61.02 가 달라, 어느 값을 「현재가」로 쓸지 정해야 한다.
