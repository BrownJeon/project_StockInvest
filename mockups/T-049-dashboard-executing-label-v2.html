대시보드 맨 아래 "내 결정" 섹션 추가 + 주문 상태 표시 정정

대시보드 위쪽 섹션은 그대로이고(회색 윤곽으로만 표시), 맨 아래에 "내 결정" 섹션 하나가 붙습니다. 섹션 안 구성(기간 1일·7일·30일, 전체·승인·거절·만료 칩, 카드 목록 7건 + 페이저)은 분석 화면에 있던 MyDecisionTab 그대로이고, executing 카드의 상태 문구만 바뀝니다. 점선 파란 글씨는 데모 설명이며 앱에는 나오지 않습니다.

⚠ 먼저 알아 둘 사실

  • 이 "내 결정" 화면은 6월 중순 이후 앱 어디에도 연결돼 있지 않았습니다(분석 화면 탭에서 빠짐). 대시보드에 붙이면 그때 이후 처음 다시 보이는 화면입니다.
  • 최근 기록은 만료가 대부분이라, 기간 7일·필터 "전체"로 열면 만료 카드만 줄지어 보일 가능성이 높습니다. → 결정 ②
  • 거절 카드의 "1시간 뒤 가격 변화"는 지금 시그널 API 가 그 값을 내보내지 않아 항상 "거절됨"으로만 보입니다(이번 데모도 그렇게 그렸습니다).
  • 주문 상태 문구는 주문 기록(orders)의 상태를 함께 읽어야 정확해집니다(v1 에서 승인된 D1). 시그널 API 에 주문 상태 필드가 추가됩니다.

v1 에서 바뀐 점

  • 위치: 분석 › 내 결정 → 대시보드 맨 아래 섹션.
  • 번호 있는 주문의 문구를 대시보드 "최근 주문" 섹션과 같은 말·같은 색으로 맞췄습니다(접수됨·부분체결·체결됨·취소됨·테스트). 같은 화면에서 같은 주문이 두 가지로 보이지 않게 하려는 것입니다. v1 의 "모의"는 KIS 모의투자 계좌와 헷갈려서 "테스트 · 실주문 아님"으로 바꿨습니다.
  • "주문 처리 중" 앞의 ⏳ 이모지를 뺐습니다(기기에서 노랗게 그려져 경고처럼 보였음 — v1 자체 점검 P2).
  • 만료 카드: 반투명(opacity 0.65) 대신 점선 테두리로 구분합니다. 반투명 회색 글자는 대비가 약 3:1 로 기준(4.5:1) 미달이었습니다.
  • 버튼(기간·필터·페이저)의 터치 영역만 44px로 키웠습니다. 보이는 크기는 원본 그대로입니다.
  • 불러오기 실패 시 원본은 "결정 내역 없음"으로 보였습니다(오류를 빈 목록처럼 표시). 확인 필요 주문이 숨지 않도록 오류 상태를 따로 둡니다.

2. 상태별 카드 한눈에 (권고안 기준, 같은 합성 데이터 12건)

위 제안 화면은 7건씩 나눠 보여 주므로, 비교하기 쉽게 전부 펼쳐 둡니다. 색만으로 구분하지 않습니다 — 확인 필요는 ⚠ 아이콘 + 테두리 칩 + 카드 테두리 + 안내 줄, 나머지는 문구로 구분됩니다.

3. executing 표시 규칙 (코드로 확인한 주문 상태 기준)

조건은 시그널 상태가 executing 일 때입니다. "번호"는 시그널에 연결된 주문 번호(consumed_order_id), "주문 상태"는 그 주문 기록의 status(+blocked_by)입니다. 표에 없는 조합이 오면 확인 필요로 표시합니다(안전한 쪽).

4. 결정 필요

v1 에서 정한 것(문구 A안 · 주문 상태로 구분 D1 · 안내 줄 항상 표시)은 다시 묻지 않습니다. 대시보드에 붙이면서 생긴 두 가지만 묻습니다. 대시보드 재개편 전 임시 배치라는 점을 기준으로 권고했습니다.

① 섹션 기본 상태

A · 기본 접힘 권고머리 줄에 "승인 n · 거절 n · 만료 n"과 확인 필요 건수(⚠ 칩)만. 누르면 원본 구성이 펼쳐짐. 대시보드 길이 +약 60px
B · 항상 펼침원본 그대로. 누를 필요 없이 바로 보이지만 대시보드가 약 600px 더 길어짐

운용 전략·평가 깔때기·최근 주문도 기본 접힘이라 같은 동작입니다. 접혀 있어도 확인 필요 주문이 있으면 머리 줄 칩으로 보입니다. 단, 맨 아래라 스크롤해야 보이므로 확인 필요의 1차 알림은 텔레그램 경보(T-046)입니다.

② 펼쳤을 때 목록 길이 (기간 기본 7일은 그대로)

7건 + 페이저 권고원본 그대로. 새 규칙이 없어 재개편 때 버릴 것도 없음
3건 + "더 보기"펼친 뒤 길이가 짧음. 누르면 7건 + 페이저로 바뀜. 새 동작 1개 추가

A(접힘)를 고르면 길이 문제는 이미 풀리므로 원본을 유지하는 편이 구현·검증 범위가 작습니다. B(펼침)를 고른다면 3건안이 낫습니다.

5. 모바일·접근성 점검 메모

  • 360·412px: 상태 문구는 원본처럼 한 줄 말줄임, 안내 줄·요약 줄은 줄바꿈 허용 → 가로 스크롤 0.
  • 명암비(카드 배경 #171a21): 경고 노랑 8.1:1 · 접수됨 남색 5.9:1 · 체결됨 초록 7.7:1 · 회색 5.7:1 · 빨강 4.6:1.
  • 섹션 머리 줄은 버튼(펼침 여부를 화면 낭독기에 알림), 기간·필터는 눌림 상태를 알리는 버튼, 터치 영역 44px.
  • 아이콘은 화면 낭독기에서 숨기고, 확인 필요 칩에는 "경고:" 숨김 텍스트를 붙입니다.
  • 건수(전체·승인·거절·만료)는 원본처럼 불러온 목록 안에서 셉니다. 원본은 최대 200건까지만 불러오므로 기간이 길면 실제보다 적게 보일 수 있습니다.
