## 표본 선정 규칙 (D-07 — 미국 이벤트 단계 공통, 노트 작성 **전**에 끝낸다)

2. **후보 좁히기(도구일 뿐, 자격 근거가 아님)**: `us_earnings_events` 의 추정 창이 [작성일 다음 거래일, +14일]과 겹치는 종목. 예: `SELECT symbol, window_start_et, window_end_et FROM us_earnings_events WHERE superseded_by IS NULL AND window_end_et >= '<작성일>' AND window_start_et <= '<작성일+14일>' ORDER BY symbol`. 추정은 8-K 접수 패턴으로 계산한 것이라 틀릴 수 있다.
3. **자격 확인(공식 확정 일정)**: 좁힌 종목마다 회사 IR 보도자료·8-K 로 **확정된 발표일**을 확인한다(웹 검색 허용 — D-02 조건 a~e: 질의에는 회사명·티커·분기·이벤트 종류만, 보유 정보 금지, 출처 URL·조회일 기록). 확정이 확인되고 발표일이 작성일 다음 거래일 ~ +14일 안이면 **자격 있음**. 공식 확정이 없는 종목은 후보에서 뺀다.
4. **층별 추첨**: 나스닥 층·NYSE 층 각각 자격 종목을 티커 알파벳순으로 정렬하고, 시드 = 작성일 `YYYYMMDD` 정수로 결정적으로 1종목 추첨한다: `python3 -I -c "import random;L=sorted([...]);print(random.Random(<시드>).choice(L))"`. **손으로 고르지 않는다.** 한 층에 자격 종목이 없으면 사유를 기록하고 단계를 미루거나 다른 층에서 보충(기록).
5. **노트 작성 전 기록**: T-061 `## Analyst` 에 풀·좁힌 목록·자격 목록(출처 URL·조회일)·시드·추첨 결과를 먼저 적는다. 추첨 뒤 바꾸지 않는다(자격 오류가 발견되면 사유와 함께 재추첨하고 이전 기록을 남긴다).
6. **코스닥 보조 관찰(비판정)**: 풀 = 앱 국내 유니버스의 코스닥 종목(`src/lib/strategy/universe.ts` `KOSDAQ_TOP` 상시 포함 10종목 + DB `universe_always_include` 에 코스닥이 있으면 추가). 같은 방식(티커순 정렬·시드 = 작성일)으로 2종목 추첨, 테제 노트(국내 L0, 웹·Bash 금지).
