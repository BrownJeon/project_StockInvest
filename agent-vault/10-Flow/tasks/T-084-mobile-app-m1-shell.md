# T-084 — 모바일 앱 "주식캐기" M1 (셸 APK + 다운로드·업데이트)

> 정본 절차서: [`docs/mobile-app-procedure.md`](../../../docs/mobile-app-procedure.md) — 마일스톤 M1~M4 중 **M1**. M2(텔레그램 링크→앱 열기)·M3(앱 잠금)·M4(푸시)는 M1 배포·실기기 확인 뒤 별도 task 로 번호를 받는다.

## 목표

- 사용자 요청: 구현된 StockInvest 웹앱을 일본어교육(TheKaiwa)과 같은 방식의 안드로이드 앱으로 만들어 앱으로 구동한다. 앱 이름 **주식캐기**.

- 비범위(M1): Google/GitHub 로그인(앱), 앱 잠금, 푸시, 텔레그램 링크→앱, 플레이스토어, iOS. 매매·주문·cron·KIS 로직 변경 없음.
