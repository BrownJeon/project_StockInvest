# T-109 — 최근 3일 종목 리서치 참고 연결

## 사용자 요청·목표

T-107 대화에서 사용자가 종목의 매수/매도 분석 시 동일 종목의 최신 리서치 결과를 참고하는 구조를 제안했고, 사용 기한을 **최신 3일**로 지정했다. 작업으로 접수하되 이 문서 자체가 구현·검증·운영 반영을 뜻하지 않는다. 상세 배경과 제안: [분석 절차 보고서 §4.3](../../../docs/reports/2026-10-28-analysis-processing-flow.md).

## 범위와 작업 원칙

- 동일 종목·시장 일치, 최신 결과의 마지막 일봉 기준일 확인. 3일의 세부 해석은 일단 거래소 현지 판단일 포함 최근 3개 달력일(D-2~D)로 기록하며, 사용자가 정한 3일을 3거래일로 연장하지 않는다. 오류·결측·미래/미확정 자료는 사용 불가 사유를 남긴다.
- 초기에는 장마감 AI BUY/SKIP 후보에 리서치를 보조 정보로 결합하는 경로를 대상으로 기존 결과와 비교한다. 장중 룰과 매도/보유 청산은 각각 별도 영향 분석·검증을 거친다. 필수 손절·기존 안전장치를 리서치로 우회하거나 지연하지 않는다.
- 참고 정보·원본 시각·표본·출처·상태와 판단 당시 입력 스냅샷을 기록한다. 과거 저점 근방 적중률은 실제 수익률이 아니다. 자료가 없으면 기존 분석을 계속한다.
- 동일 후보/시점으로 기존과 보조자료 추가 결과를 비교하되, 최초에는 추가 판단을 주문에 반영하지 않는 shadow 평가. 미국 수수료 편도 0.25%, 슬리피지·체결·자금·검증 관문을 반영해 비용 후 성과와 낙폭을 평가한다. 추천 결과/사용자 지시만으로 전략을 검증 상태로 승급하지 않는다.
- 데이터 기준일·스냅샷 공개/생성시각을 고정해 미래 정보 혼입을 막는다. T-078 통합 절차서·단일 실행 원장의 현재 단계와 조율한다. 분석·주문 변경은 구현 시 해당 안전경로의 독립 Reviewer·QA 등 프로젝트 절차를 따른다.

## 현재 상태

접수·작업계획 반영만 완료. 소스 구현, 모의 평가, 실매매 적용, DB 변경과 배포는 아직 없다. T-068 품질 재검토는 이 작업 범위에 포함하지 않는다.
