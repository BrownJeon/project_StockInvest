## 범위 (Analyst P1 + §5 결함 목록 그대로 — 새 요구를 만들지 않는다)

6. 출력: **새 리포트 파일**(예: `T-095-signal-postmortem-v2-<KST 날짜>.md` — v1 파일은 덮어쓰지 않는다)과 선택적 `--json`. 읽기 전용 세션(`SET SESSION TRANSACTION READ ONLY`) 유지.
