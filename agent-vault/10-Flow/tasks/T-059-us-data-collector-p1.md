## 1. 목적

분석가가 미국 종목을 **관측값**으로 분석하게 한다. 지금 `stock_fundamentals` 는 7행 전부 LLM 기억값(`data_source='claude_ai'`)이고, 미국 실적일·직전 실적·공시를 앱이 갖고 있지 않다. 이 task 는 **읽기 전용 외부 수집 + DB 적재 + 조회 API 1개**까지다. 시그널·카드·주문 경로는 건드리지 않는다.

## 2. 범위

## 3. 테이블 5개 (분석가 설계, T-057 §5 — 컬럼은 설계 값이며 개발자가 타입·인덱스를 확정)

| 테이블 | 핵심 컬럼 | 비고 |
|---|---|---|
| `symbol_cik_map` | symbol, cik, source, verified_at | `https://www.sec.gov/files/company_tickers.json` 로 채움 — **선언된 UA 로 200 확인됨**(2026-10-21, 10,443건, INTC·AMD·MU·ORCL·NVDA·SNDK·AVGO·TSM 매핑 확인, ETF `SMH` 는 없음 → ETF 는 수집 대상 아님). 이전 403 은 연락처 없는 UA 때문 |
| `us_filings` | cik, accession, form, items, report_date, filed, primary_doc_url | 8-K `items` 에 `2.02` 가 있는 행이 과거 실적 발표일 |
| `us_financial_facts` | cik, taxonomy, tag, unit, frame, start, end, val, form, filed, accn | companyfacts 의 **`frame` 이 있는 분기·연간만** 적재. YTD 누적 행 배제 |
| `us_earnings_events` | symbol, fiscal_period, event_date_et, event_time_class[BMO/AMC/unknown], **status[confirmed/estimated/manual]**, source_kind, source_url, observed_at, superseded_by | `confirmed` = IR 보도자료 등 공식, `manual` = 사용자/분석가 입력, `estimated` = 패턴 추정(±7일 창만, **날짜 단정 금지**) |
| `us_fundamentals_snapshot` | symbol, per, pbr, eps, bps, market_cap, shares, h52, l52, sector, observed_at | KIS price-detail 원값. 회계 기준·갱신 주기는 미확인이라 **원값 그대로 + observed_at** |

> ⚠ 분석가 표의 문구는 "테이블 4개"이나 나열된 것은 5개다(보고서 요약은 5개) — **5개가 맞다**(Leader 대조).

**시각 저장 규칙(T-046 재발 방지)**: DB 시간대는 KST, 앱 풀은 `timezone:'+09:00'`. `event_date_et` 는 날짜(ET 현지) 컬럼, `observed_at`·`filed` 는 앱 풀 규약대로 KST DATETIME. UTC `toISOString()` 문자열을 DATETIME 에 넣지 않는다.

## 4. 수집 규칙

1. **SEC**: 모든 요청에 `SEC_USER_AGENT`(환경변수, 회사명+연락 이메일 형식)를 넣는다. **env 가 비어 있으면 SEC 를 호출하지 않고** 오류 로그를 남긴 채 그 job 을 건너뛴다(연락처 없는 요청이 403·차단의 원인이었다). 직렬 호출, **10 req/s 미만**(권장 5 req/s 이하), 429·403 시 지수 백오프 후 중단, `If-None-Match`/`filed` 기준 증분.
2. 대상 종목은 **보유 + 즐겨찾기 + 정적 universe 50** 의 해외 심볼 중 CIK 가 매핑된 보통주. ETF·미매핑은 건너뛰고 로그에 사유를 남긴다.
3. `edgar-sync` 는 매일 07:00 KST(미국장 마감 뒤·국내장 개장 전). 종목당 submissions 1 + companyfacts 1 호출. 실패한 종목은 다음 날 재시도하되 **기존 행을 지우지 않는다**.
4. `kis-fundamentals-snapshot` 은 하루 1회(KIS 호출은 기존 스로틀·장중 호출 부하를 피해 개장 전 시각으로 — 개발자가 `cron-runner.sh` 의 기존 슬롯을 보고 제안). 읽기 전용 GET 만.
5. 외부 응답이 비었거나 형식이 다르면 **0·NULL 로 채우지 않고 행을 쓰지 않는다**(T-056 원칙). 파싱 실패는 종목 단위로 격리한다.
6. 실적 일정: 8-K 2.02 보고일 이력으로 다음 분기 **±7일 창**만 `estimated` 로 계산한다. `confirmed`/`manual` 은 사람이 넣는 경로(관리 SQL 또는 스크립트)로만 — 자동 스크래핑은 이 task 범위 밖.
7. 개인정보·보유 정보: SEC·KIS 요청에 보유 수량·평단을 실어 보내지 않는다(심볼·CIK 만).
