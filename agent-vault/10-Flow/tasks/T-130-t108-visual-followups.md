## 범위 (T-128 의 해당 번호를 그대로 옮김)
1. **설정 화면 기존 컨트롤 44px 미만 10개**(QA 면제 사유, 360px 실측): 「미적용›」「60분 ›」「-2% ›」「-4% ›」「-7% ›」등. [[T-104-cron-jobs-market-grouping]] WP5(설정 화면)와 **같은 파일** — T-104 는 아직 시작 불가(T-117~119 뒤 1주 관찰, ~11-05)이므로 Designer 가 T-104 의 설정 화면 계획과 충돌하지 않는지 먼저 본다.
3. **확인 필요 머리 숫자**: 「확인 필요 4건」(묶음 단위)과 하단 「데이터 이상·분석 실패 6건」이 병기돼 혼동 — 머리 숫자의 의미(묶음 수 vs 항목 수)를 Designer 가 정한다.
4. **영문 코드 노출의 한국어 문구**: 청산 가동 줄 「! 조회 실패 · balances_unknown」 등 — 문구 자체를 Designer 가 정한다(사전의 **구조 단일화**는 T-128 WP-A 가 한다. 이 task 는 사용자에게 보이는 문구만).
5. **「차단」 표기 규칙 3개**: 스위치는 「모든거래차단」 한 낱말, 시그널은 「검증 관문」과 함께, 주문은 사유와 함께.
6. **분석 상세 `skipped` 표기 불일치**: 홈·거래의 「⊘ 차단」과 전략 화면의 「건너뜀」이 같은 시그널(검증 관문에 막힌 장마감 시그널)을 다르게 부름 — `indicators.gate` 분기 필요.
10a. **용어 혼재**: 「트레일링」「익절」과 「트레일링 스탑」「목표 익절」이 화면에서 섞여 있다(용어표 §12 에 없음) — 하나로 정한다.
