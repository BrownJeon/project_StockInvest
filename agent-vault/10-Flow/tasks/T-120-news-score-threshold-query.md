## 알려진 사실 (T-105 기록 요약 — 근거는 T-105 task)
- 임계 `DEFAULT_MIN_SCORE = 0.5` (`src/lib/rag/retrieval.ts:35`, bge-m3 기준 "0.5 미만은 노이즈"). 질의는 후보 지표 수치 문자열(`종목코드 패턴 …: RSI=28 …`)이라 기사 의미와 멀다.
- 10-28 읽기 전용 재현: 필터 통과 기사 5건 유사도 0.34~0.49, 후보형 질의 최고 0.408~0.422, 시황형 질의 최고 0.480, 0.5 이상 0건. 임계만 낮추면(0.35 → 5건) 후보와 무관한 기사(농협 펀드케어·탄소중립 성장률 등)가 LLM 입력에 섞여 D-2 의 환각 방지 의도가 훼손된다. 점수는 앱 질의의 근사 재현이라 [가능성 높음] 수준.
- 선택지: (가) 임계 유지·뉴스 없이 운영 / (나) 뉴스용 **시황 질의**를 따로 쓰고 임계 0.4 전후(시장 배경 5건 목적) / (다) 종목별(회사 단위) 뉴스·공시 원천 결합 — **설계를 처음부터 다시 잡는 일은 아니다**(2026-10-29 22:xx 정정: 위 "새 데이터 원천·별도 설계"는 10-28 오후 T-105 기록 문구이고, 그날 밤 완성된 2차 설계서 `docs/design/2026-10-28-corporate-intelligence-second-design.md`(v1.0)가 이 아이디어를 이미 흡수했다 — `ci_*` 테이블 + 결정적 회사 단위 조회, RAG 는 유지, RAG 임계·질의 문제는 본 T-120 이 별도로 다룬다). 시장별로 다르다:

  - **국내**: **새 설계 필요** — 설계서가 단계 6(후속)으로 미뤘다. DART 는 키·약관·연결 흔적이 없고, 현재 국내 뉴스 원천은 연합뉴스 경제 RSS 1개(일반 헤드라인)뿐이다. `ci_*` 가 `source_kind` 어댑터로 원천 추가를 받을 수 있게 열려 있어 구조를 갈아엎는 것은 아니지만, 원천 선정·약관 확인·종목 식별 규칙은 새로 정해야 하고 원천 선정·약관 검토는 사용자 결정 사항이다.
