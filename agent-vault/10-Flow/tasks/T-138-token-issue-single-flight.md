## 우리 쪽 결함

`issueAndStore` 를 부르는 두 경로 중 **한쪽만 단일화돼 있다.**

- `invalidateKisToken()` — `refreshInFlight` 로 합친다(예전부터).
- `getKisToken()` 의 캐시 미스·만료임박 폴백 — **합치지 않는다.** T-136 이 「진행 중인 재발급이 있으면 합류」를 넣었지만(`if (refreshInFlight) return refreshInFlight;`), **그 플래그를 세우는 쪽이 `invalidateKisToken` 뿐**이다. 갱신 시각의 폭주는 전부 이 폴백 경로이므로 **합류할 대상이 없다.**

T-136 시험이 이 공백을 `test.failing` 으로 이미 적어 뒀다 — 「`getKisToken` 끼리의 동시 호출도 발급 1회여야 한다 — 아직 아니다」. **이 task 가 그 시험을 통과시킨다.**
