## 설계 요지 (상세는 작업서)

- `createSignal` 에서 **블랙리스트 뒤 · 중복 검사/INSERT 앞**, 매수일 때만 실시간 현금 점검. 부족하면 행·알림·RAG 색인 모두 없이 `{ ok:false, signalId:0, errorCode:'insufficient_cash' }`.
- 필요 금액 = 수량 × 호가 추격 반영 지정가 × 1.002. 현금이 **엄격히 적을 때만** 막는다(같으면 통과).
- **모르면 막지 않는다**: 조회 실패·8초 초과·`unknown`/`not_queried`·값 이상·시장가·수량/가격 미확정·환율 없음·**해외 단위 미확정**.
- 흔적: 서버 로그 1줄 + 기존 퍼널/`trade_logs` 방식의 건너뜀 집계. (심볼, 방향) 1시간 스로틀(룰은 매 틱 재발화). 텔레그램·슬랙으로는 절대 안 보냄. 해외 건너뜀은 국내와 따로 센다.
- 스위치(재배포 없이): `system_config` 의 `signal_cash_gate_domestic_enabled` / `signal_cash_gate_overseas_enabled` — **키 없음·`true` = 켜짐, 그 밖의 모든 값 = 꺼짐.**
- 제외: 매도, post-market 엔진·`custom/confirm`(직접 INSERT 경로), entry-watcher T-051, `submitOrder`·`order-limits`·`kill-switch`·`dry-run`.
- T-044 흡수 시 같이 반영: Codex low(`notify_skip_unexecutable` 비정상 값 → 보낸다) · Reviewer Low-1(`approval-context.ts` 주석만) · Low-2(문서에 생략 로그 위치 `pm2-out.log` + grep 문구).
