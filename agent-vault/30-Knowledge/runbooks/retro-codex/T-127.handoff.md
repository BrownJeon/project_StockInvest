# 소급 독립 검토 요청 — T-127 크론 러너 스풀 후속 보강 (이미 운영 중)

## 배경
StockInvest 의 크론 러너(`scripts/cron-runner.sh`, bash, pm2 가 상시 실행)는 매 틱 여러 잡의 HTTP 호출 결과를 로컬 스풀 파일에 줄 단위로 쌓아 서버(`/api/cron/job-run-log`)로 보낸다(실행 기록 `job_run_log`). 일부 호출 응답 본문에는 **금액**(총자산·손익)이 들어 있어, 그 값이 스풀·로그·DB 에 남지 않게 하는 것이 이 변경의 목적이다. 10-31 에 운영 반영됐고 내부 Reviewer·QA 는 통과했다 — 당신은 **추가의 독립 적대적 검토**다.

## 변경 (이 diff 전체)
1. 금액을 싣는 두 라벨(`portfolio-snapshot`·`trade-report`)의 본문을 스풀에 넣기 전에 `jrl_mask_money` 로 마스킹: 키 `totalKRW|KRW|USD|headerPnlKRW|lifoPnlKRW` 의 숫자 값을 0 으로, `detail` 은 빈 문자열로. **마스킹이 실패하면 원문이 아니라 빈 본문**이 스풀에 남는다.
2. 스풀 파일 0600: `jrl_hook` 안에서만 `umask 077` 을 걸고 반환 직전에 복원. 러너 전체 umask 는 바꾸지 않는다. 서브셸(`( umask 077; … )`)은 `JRL_FAILING` 같은 셸 변수를 잃으므로 금지. `jrl_flush` 는 `_jrl_flush_body`(여러 `return` 경로)를 감싼 얇은 겉함수.
3. 전송 실패 로그에 `reason=<분류어>`. 서버 `src/lib/strategy/records/job-run-log.ts` 의 503 사유 `console.warn` 한 줄.
4. 시험: `scripts/test-cron-runner-job-run-log.sh` (J9 마스킹·J10 umask·J11 503 사유), `records/__tests__/job-run-log*.test.ts`.

## 불변 조건
- 마스킹은 JSON 구조를 깨지 않고, 목록 밖 키의 값은 건드리지 않는다. 스풀 줄 형식 `v1\t…` 와 러너의 반환값·`CALL_LAST_CODE`·`curl` 인자·다른 잡 동작은 그대로. 스풀은 항상 0600.

## 수용된 한계 (근거 없이 버그로 보고하지 말 것)
숫자 문자열(`"KRW":"123"`)과 키·값 사이 줄바꿈은 마스킹되지 않는다(현재 라우트는 compact JSON 을 낸다) · 마스킹 라벨은 두 개로 고정 · 롤업 `runs` 는 재전송으로 근사값.

## 답해 줄 질문
(a) 마스킹 우회 경로: 이스케이프된 따옴표 안의 키 이름, 중첩 객체, 같은 키 중복, 큰 수·지수 표기·음수·소수, 키 이름 접두/접미 일치(`totalKRW2` 등)로 **금액이 스풀에 남는** 경우. (b) umask 저장·복원이 `return`·오류·`set -e/-u` 환경에서 새는 경우. (c) 셸 인용·특수문자(라벨·경로·본문의 공백·따옴표·개행·`%`·`\`) 처리. (d) 서버 503 사유 로그가 비밀이나 금액을 싣는가. (e) 시험이 위 불변을 **실제로** 고정하는가(약한 단언, 변이에 안 깨지는 시험).
읽기 전용으로 `git diff`, grep, 작은 셸 스니펫 실행(임시 디렉터리)으로 직접 검증해도 좋다. 저장소 파일은 수정하지 말 것.
