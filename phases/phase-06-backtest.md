# Phase 6 — 백테스팅·수익 분석 대시보드 ⬜

**목표:** 과거 데이터로 전략을 시뮬레이션해 샤프·MDD·승률 등 핵심 지표를 산출하고, 실거래 성과와 비교할 수 있게 한다.

## 작업 범위

- [ ] `src/lib/strategy/backtest.ts` — 캔들 시계열 + 전략 함수 → 거래 리스트·에쿼티 커브
  - 수수료·슬리피지 반영 (analyst가 제시한 기본값 사용)
  - look-ahead bias 방지 (시그널 시점 봉의 다음 봉 시가로 체결 시뮬)
- [ ] DB — `backtests` 테이블
- [ ] 대시보드 — 에쿼티 커브, 거래 내역, 지표 요약
- [ ] 라이브 vs 백테스트 괴리 리포트

## 검증

- analyst가 제시한 샘플 전략·기간에서 참고 수익률과 일치
- 동일 입력 재실행 시 결정적 결과

## 이 Phase에서 추가·수정하는 화면 (docs/screens.md)

- **분석** (`/analytics`) — **핵심 구현**:
  - 수익률 대시 (기간 토글 + 누적 차트 + 승률/샤프/MDD/손익비)
  - 백테스트 실행 (`/analytics/backtest`) — 전략·기간·초기자본·수수료·슬리피지 입력 + 진행률
  - 백테스트 결과 (`/analytics/backtest/:id`) — 에쿼티 커브·거래 리스트·라이브 vs 백테스트 괴리
- 전략 상세 → 백테스트 실행 연결 (`/analytics/backtest?strategy=<id>`)
- 감사 로그 확장 — 주문·시그널·체결 통합 조회
